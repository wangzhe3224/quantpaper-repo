# 通过学习排序构建横截面系统化策略

**Daniel Poh, Bryan Lim, Stefan Zohren, 和 Stephen Roberts**

> 摘要 — 横截面系统化策略的成功关键在于在组合构建之前准确地排列资产。现有技术通常使用简单启发式方法或对标准回归或分类模型的输出进行排序来完成这一排名步骤，这在其他领域（如信息检索）中已被证明是次优的排序方法。为了解决这一不足，我们提出了一个通过引入学习排序算法来增强横截面组合的框架，该算法通过学习工具之间的成对和列表级结构来提高排名准确率。以横截面动量作为示范性案例研究，我们展示了使用现代机器学习排序算法可以显著提高横截面策略的交易表现——与传统方法相比，夏普比率约提高了三倍。

---

## I. 引言

横截面策略是系统化交易中一种流行的风格——学术界在不同交易洞察和资产类别中记录了众多变体[1]。与独立考虑每个资产的时间序列方法[2]不同，横截面策略通过资产之间的相对交易来捕获风险溢价——买入预期收益最高的资产，卖空预期收益最低的资产。例如，[3]的经典横截面动量策略通过排列过去一年的收益率来选择股票，并押注收益的排序将在未来持续——买入排名前十十分位的资产，同时卖空排名后十十分位的资产。通过做多赢家、做空输家，横截面策略已被证明更能抵御一般市场波动，即使在资产具有不可忽略的相关性时（如股票市场）也能表现出色[1, 4, 5]。

近年来，随着机器学习的兴起，许多引入先进预测模型的横截面系统化策略被提出[6–8]，通常显示出相对于传统基准的显著改善。一般来说，这些机器学习模型以监督方式训练，旨在最小化持有期内预测收益的均方误差（MSE）。虽然此框架下的回归模型能准确提供未来资产收益的均值估计，但它们没有显式考虑收益的预期排序——而这正是横截面策略设计的核心。这可能因此对策略表现产生负面影响，并导致次优的投资决策。

标准回归方法在排序方面的局限性已在信息检索应用中被广泛研究，并提出了多种指标和方法[9]。这些方法统称为学习排序（LTR）[10]，如今的变体利用了深度神经网络和基于树的方法等现代学习技术[11–13]——在准确率方面相比简单基准取得了巨大进步。虽然LTR算法在金融领域也有一定程度的应用，但大多数论文集中在其在简单股票推荐中的使用[14]，缺乏用于开发和评估一般横截面策略的框架。

在本文中，我们展示了LTR模型如何用于增强传统横截面系统化策略——以横截面动量作为示范性用例。我们首先将股票选择转化为一般的排序问题，这使得在不同LTR算法之间灵活切换以及纳入其他领域开发的先进模型成为可能。接下来，我们将LTR模型与标准监督学习方法和启发式基准进行具体评估。通过对美国股票的测试，我们证明了成对和列表级模型实质性地提高了股票排名准确率——采用LTR方法带来了策略整体表现的改善。最后，虽然我们的排序算法使用动量预测因子，但其模块化特性允许调整输入以纳入其他特征集——为一般横截面策略提供了一个新颖且可推广的框架。

## II. 相关工作

### A. 横截面动量策略

动量策略可以分为（单变量）时间序列动量或（多变量）横截面动量。

在时间序列动量中，资产的交易规则仅取决于其自身的历史收益。该策略由[2]首次提出，记录了在25年内单独交易近60种不同流动性工具的盈利能力。这引发了大量后续研究，如[1, 15, 16]，探索各种交易规则以及不同的趋势估计和仓位管理技术，旨在完善整体策略。

横截面动量采用类似的理念，但侧重于比较资产的相对表现。其特点是首先按表现（通常取收益率）对工具进行排序，然后买入一部分表现最佳的资产（赢家），同时卖空类似比例的表现不佳的资产（输家）。自从[3]在美国股票市场考虑此策略的早期工作以来，相关文献已经非常丰富——从报告动量现象在其他市场和资产类别中存在的研究[17–22]，到提出改进策略各方面新方法的研究。例如，[6]使用前瞻夏普比率而非历史收益进行排名。[23]基于各自波动率标准化的收益构建排名，认为这允许更公平地比较工具表现；[1]采用类似但更复杂的方法，使用波动率归一化的移动平均收敛发散（MACD）指标作为输入。近期研究的一个共同点是它们采用先回归后排序的方法[24]——先最小化收益预测与目标之间的误差，然后对输出进行排序，最后通过交易排序结果的尾部来构建零投资组合。值得注意的是，常用的损失函数是MSE（均方误差），它是一个逐点函数，使用MSE训练的论文实例包括[6]和[8]。

在回顾与横截面动量相关的研究后，我们相信这是第一篇考虑使用排序算法来增强横截面动量策略的论文。我们提出使用学习排序算法，而非基于启发式或基于逐点损失训练模型产生的输出进行排名——证明了学习证券之间的成对和列表级结构能产生更好的排名，进而带来更好的样本外策略表现。

### B. 金融中的学习排序

学习排序是信息检索领域的一个关键研究方向，专注于使用机器学习技术训练模型来执行排序任务[10, 25]。信息爆炸以及硬件（基于云的GPU和TPU[26]）和软件（如TensorFlow[27]和PyTorch[28]等开源深度学习框架）方面的现代计算进步，引发了机器学习算法设计方式的转变——从需要手工制作和显式设计选择的模型转向采用神经网络以数据驱动方式学习的模型。这引发了排序模型空间的并行趋势，研究人员从使用无需训练的概率方法（如BM25和LMIR（信息检索语言模型））[10]，转向基于上述发展构建的复杂架构[9]。

如今，LTR算法在搜索引擎[25]、电子商务[29]和娱乐[30]等众多商业应用中发挥着关键作用。这些算法在金融领域的探索程度较为有限，具体应用于股票情绪分析和排名的研究见[24, 31]。[31]将RankNet和ListNet应用于十年的市场和新闻情绪数据，证明相对于标普500指数收益、HFRI股票市场中性指数（HFRI EMN）以及纯情绪技术具有更高的风险调整后盈利能力。另一方面，[24]记录了LambdaMART在预测深圳证券交易所日内收益方面相对于标准神经网络的优越性，采用了基于订单簿的特征。

尽管初步结果令人鼓舞，但我们注意到这些应用没有考虑与传统系统化交易风格的比较——仅在[31]中与市场收益比较，在[24]中与神经网络模型比较——使得难以评估LTR方法带来的真正价值增值。排名方法也是针对特定的情绪交易应用定制的，难以推广到其他类型的横截面交易策略。我们在本文中明确解决了这些局限性——提出了一个将LTR模型纳入横截面策略的一般框架，并评估其表现。

## III. 问题定义

给定一个每月再平衡的证券组合，横截面动量（CSM）策略在τ_m的收益可以表示为：

$$r^{\\text{CSM}}_{\\tau_m, \\tau_{m+1}} = \frac{1}{n_{\\tau_m}} \sum_{i=1}^{n_{\\tau_m}} X^{(i)}_{\\tau_m} \frac{\sigma_{\\text{tgt}}}{\sigma^{(i)}_{\\tau_m}} r^{(i)}_{\\tau_m, \\tau_{m+1}} \\tag{1}$$

其中 τ_m, τ_{m+1} ∈ T ⊂ {1, ..., t−1, t, t+1, ..., T}，T 表示与每月最后一个交易日重合的索引集合；r^CSM_{τ_m,τ_{m+1}} 是从 τ_m 到 τ_{m+1} 月的实现组合收益，n_{τ_m} 指组合中的股票数量，X^{(i)}_{τ_m} ∈ {−1, 0, 1} 表征证券 i 的横截面动量信号或交易规则。我们每月再平衡以避免高频交易（例如每日交易）带来的过高交易成本。我们还固定年化目标波动率 σ_tgt 为15%，并用 σ^{(i)}_{τ_m} 缩放资产收益，后者是事前月度波动率的估计量。在本文中，我们对 σ^{(i)}_{τ_m} 使用63天跨度的滚动指数加权标准差，但注意到可以使用更复杂的方法（如GARCH[32]）。

### A. 策略框架

CSM策略的一般框架包含以下4个组成部分。

**1) 分数计算：**

$$Y^{(i)}_{\\tau_m} = f(\mathbf{u}^{(i)}_{\\tau_m}) \\tag{2}$$

给定资产 i 在 τ_m 时的输入向量 u^{(i)}_{τ_m}，策略的预测模型 f 计算其对应的分数 Y^{(i)}_{τ_m}。对于 τ_m 时大小为 N_{τ_m} 的横截面资产池，被考虑交易的资产分数列表表示为向量 Y_{τ_m} = {Y^{(1)}_{\\tau_m}, ..., Y^{(N_{\\tau_m})}_{τ_m}}。

**2) 分数排名：**

$$Z^{(i)}_{\\tau_m} = R(Y_{\\tau_m})^{(i)} \\tag{3}$$

其中 Z^{(i)}_{τ_m} ∈ {1, ..., N_{τ_m}} 是对运算符 R(·) 将分数按升序排列后资产 i 的位置索引。

**3) 证券选择：**

$$X^{(i)}_{\\tau_m} = \begin{cases} -1 & Z^{(i)}_{\\tau_m} \leq \lfloor 0.1 \\times N_{\\tau_m} \\rfloor \ +1 & Z^{(i)}_{\\tau_m} > \lceil 0.9 \\times N_{\\tau_m} \\rceil \ 0 & \\text{Otherwise} \end{cases} \\tag{4}$$

选择通常是一个阈值步骤，其中保留一定比例的资产以形成各自的多/空组合。公式（4）假设我们使用典型的十分位大小的组合（即前10%和后10%）。

**4) 组合构建：** 最后，可以根据公式（1）对选定工具进行波动率缩放来构建简单组合。

在下一节中，我们将概述当前策略方法和LTR模型的分数计算技术。

## IV. 分数计算方法

大多数CSM策略遵循这一框架，在后三个步骤上大体相似，即排名分数、选择资产和构建组合的方式。然而，它们在用于计算分数的预测模型 f 的选择上差异很大，从简单启发式[3]到基于大量宏观经济输入的复杂架构[7]。虽然计算分数的技术多种多样，但可以归为3类：经典动量、先回归后排序——两者都是现有方法——以及学习排序，这是我们提出的方法。

### A. 经典横截面动量

CSM的经典变体倾向于在分数计算中使用相对简单的程序。

**Jegadeesh & Titman, 1993 [3]:**
首次记录CSM策略的作者提出使用资产在过去3至12个月的原始累计收益进行评分：

$$\\text{Score Calculation: } Y^{(i)}_{\\tau_m} = r^{(i)}_{\\tau_m - 252, \\tau_m} \\tag{5}$$

其中 r^{(i)}_{τ_m−252, τ_m} 是资产 i 从 τ_m 起前252天（12个月）的原始收益。

**Baz et al., 2015 [1]:**
一种复杂的替代方案使用波动率归一化的MACD指标作为中间信号，通过组合不同时间尺度计算的指标形成最终信号。该指标定义如下：

$$\\tilde{Y}^{(i)}_{\\tau_m} = i^{(i)}_{\\tau_m} = \\text{MACD}(i, \\tau_m, S, L) / \\text{std}(p^{(i)}_{\\tau_m-63:\\tau_m}) \\tag{6}$$

$$\\text{MACD}(i, \\tau_m, S, L) = m^{(i)}(S) - m^{(i)}(L) \\tag{7}$$

$$\\text{std}(z^{(i)}_{\\tau_m-252:\\tau_m}) \\tag{8}$$

其中 std(p^{(i)}_{τ_m−63:τ_m}) 表示证券 i 的63天滚动标准差，m^{(i)}(S) 是资产 i 价格的指数加权移动平均，S 转换为半衰期衰减因子 HL = log(0.5)/log(1−1/S)。最终的复合信号组合了不同时间尺度上的不同波动率缩放MACD，涉及响应函数 φ(·) 以及一组短时间尺度 S_k ∈ {8, 16, 32} 和长时间尺度 L_k ∈ {24, 48, 96}，如[1]中所述：

$$\\text{Score Calculation: } Y^{(i)}_{\\tau_m} = \sum_{k=1}^{3} \varphi\left(\\tilde{Y}^{(i)}_{\\tau_m}(S_k, L_k)\\right) \\tag{9}$$

### B. 先回归后排序方法

采用先回归后排序方法的较新研究通常通过标准回归来计算分数（参见第II-A节）：

$$\\text{Score Calculation: } Y^{(i)}_{\\tau_m} = f(\mathbf{u}^{(i)}_{\\tau_m}; \\theta) \\tag{10}$$

其中 f 表征一个由 θ 参数化的机器学习预测模型，输入为某个输入向量 u^{(i)}_{τ_m}。使用波动率归一化收益作为目标，通过最小化损失来训练模型，通常使用MSE：

$$L(\\theta) = \frac{1}{M} \sum_{\Omega} \left( Y^{(i)}_{\\tau_m} - \frac{r^{(i)}_{\\tau_m, \\tau_{m+1}}}{\sigma^{(i)}_{\\tau_m}} \\right)^2 \\tag{11}$$

其中 Ω 表示工具集合和相关时间步上所有 M 个预测和目标元组的集合。

### C. 学习排序算法

LTR方法可分为逐点（pointwise）、成对（pairwise）或列表级（listwise）。逐点（成对）方法将排序问题转化为单个（成对）样本的分类、回归或有序分类，而列表级方法则使用排名列表作为输入来学习适当的排序模型。在排序性能方面，逐点方法已被观察到相对于后两种技术较为逊色[10]。此外，损失函数不仅是这些模型之间的关键区别[10]——通过纳入资产间的成对和列表级信息，使得LTR模型在本质上区别于第IV-A和IV-B节中概述的方法。

我们对与动量策略结合使用的4种LTR算法进行高层概述，重点介绍损失函数但省略技术细节以保持叙述简洁。关于将LTR框架适配动量策略的细节，请参阅附录第VII-A节。

**Burges et al., 2005 (RankNet):**
虽然将神经网络应用于排序问题的技术已经存在，但RankNet是第一个基于样本对训练网络的。与当代方法类似，RankNet使用神经网络。然而，RankNet不最小化MSE，而是专注于最小化分类样本对的交叉熵误差——基于一个元素排名高于另一个元素的概率来优化网络。由于训练使用随机梯度下降在单个样本对上进行，RankNet的复杂度与再平衡时的证券数量呈二次方关系。

**Burges et al., 2010 (LambdaMART):**
LambdaMART是一种最先进的[33, 34]成对方法，将LambdaRank[35]与多重加性回归树（MART）相结合。有趣的是，LambdaMART通过LambdaRank进行训练并不直接优化损失函数，而是利用梯度的启发式近似（称为λ-梯度）——利用了训练神经网络只需要梯度而非实际损失值这一事实。这使得模型能够绕过处理通常平坦、不连续且不可微的损失（如NDCG（归一化折损累计增益）[36]），而NDCG同时是一个流行的位置敏感信息检索指标，LambdaRank已被证明能在局部对其进行优化[37, 38]。给定λ-梯度的构造，损失涉及成对交叉熵损失与某个信息检索指标（通常取NDCG）增益的乘积[13]。另一方面，MART是一种以其灵活性著称的树增强方法。它还通过截断提供了一种简单的方式来权衡速度和准确率，这对于搜索引擎等时间关键型应用非常重要[13]。LambdaMART作为这些方法的结合体，因此将LambdaRank观察到的经验最优性（相对于NDCG）[37]与MART的灵活性和鲁棒性相结合。

**Cao et al., 2007 (ListNet):**
ListNet的开发旨在解决成对技术固有的实际问题，如其高昂的计算成本，以及其最小化与样本对分类相关误差而非整体排名的不匹配目标。ListNet通过使用列表级损失来解决这些问题，采用排列上的概率方法。首先计算分数列表和真实标签上的"top one"概率分布，然后用softmax运算符分别归一化，损失被定义为这两个分布之间的交叉熵。通过使用整个横截面证券作为输入，ListNet在 τ_m 的复杂度为 O(N_{τ_m})——比RankNet更高效，后者的复杂度为 O(N²_{τ_m})，因为训练在样本对上进行。

**Xia et al., 2008 (ListMLE):**
为了分析和提供更多理论支持来链接排序模型列表级损失函数的选择与其对应性能，[39]提出使用似然损失，因为它具有一致性、合理性和线性复杂度的优良性质。此外，似然损失是连续的、可微的和凸的[40]。这最终促成了ListMLE的开发——一种概率排序方法，将排序问题转化为最小化似然损失，或等价地最大化概率模型的似然函数。ListMLE已在基准数据集上被证明优于其他列表级方法[39]，并与ListNet共享相同的线性复杂度。鉴于我们将在本文后面进一步讨论的结果，我们注意到ListMLE和ListNet所具有的线性复杂度优势对于更大数据集可能具有相关性。

### D. 训练细节

RankNet、ListNet和ListMLE使用Adam优化器基于各自模型的排名损失函数进行训练。反向传播最多执行100个epoch，对于给定的训练集，我们将90%的数据用于训练，剩余10%用于验证。出于实际考虑，我们将目标设定为21天后的收益而非下个月的收益进行训练和验证。对于使用神经网络的LTR模型（即RankNet、ListNet和ListMLE），我们使用2个隐藏层，但将宽度视为可调超参数。使用早停法来防止模型过拟合，当模型在验证集上的损失连续25个epoch没有改善时触发。我们还在基于网络的模型中使用dropout正则化[41]作为防止过拟合的额外保障，同样将dropout率视为模型学习过程中需要校准的超参数。在所有模型中，使用HyperOpt[42]运行50次迭代搜索来调优超参数。校准超参数的更多细节可在附录第VII-B节中找到。

## V. 绩效评估

### A. 数据集概述

我们使用CRSP（证券价格研究中心）[43]的数据构建月度组合。我们的资产池包括1980年至2019年在NYSE上活跃交易的公司，CRSP股票代码为10和11。在每个再平衡区间，我们仅使用交易价格高于1美元的股票。此外，我们仅考虑具有有效价格且在过去一年中活跃交易的股票。所有价格均为收盘价。

### B. 回测和预测因子描述

除采用启发式排名的经典策略外，所有其他模型均每5年重新调优一次。校准模型的权重和超参数随后被固定，并用于下一个5年窗口的样本外组合再平衡。再平衡在每月的最后一个交易日进行。专注于排名，我们在每个多/空组合中始终交易100只股票——约占每个再平衡区间所有可交易股票的10%。对于预测因子，我们使用了第IV-A节中经典方法所采用预测因子的简单组合：

1. **原始累计收益** — 按照[3]在过去3、6和12个月期间的收益。
2. **归一化收益** — 过去3、6和12个月期间的收益，按日波动率标准化后缩放到适当的时间尺度。
3. **基于MACD的指标** — 保留[1]中公式（9）定义的最终信号，我们还通过纳入公式（6）中的原始中间信号 Ŷ^{(i)}_{τ_m}(S_k, L_k)（k = 1, 2, 3）来增强预测因子集，包括在 t 以及过去1、3、6和12个月期间计算的信号——该组共16个特征。

### C. 模型和比较指标

本文研究的LTR和参考基准模型（括号中为对应缩写）为：

1. **随机 (Rand)** — 该模型随机选择股票，作为绝对基准以了解假设以这种方式构建组合时排名指标可能呈现的面貌。
2. **原始收益 (JT)** — 基于[3]的启发式排名技术，是记录CSM策略的最早研究之一。
3. **波动率归一化MACD (Baz)** — 基于[1]提出的具有相对复杂趋势估计器的启发式排名技术。
4. **多层感知机 (MLP)** — 该模型表征了当代方法使用的典型先回归后排序技术。
5. **RankNet (RNet)** — [44]的成对LTR模型。
6. **LambdaMART (LM)** — [45]的成对LTR模型。
7. **ListNet (LNet)** — [46]的列表级LTR模型。
8. **ListMLE (LMLE)** — [39]的列表级LTR模型。

各种算法的表现最终通过两组指标进行评估——第一组包括金融中常见的指标（1到3），后者来自信息检索和排序文献（4）：

1. **盈利能力：** 样本外期间的期望收益（E[Returns]）以及组合层面正收益的百分比。
2. **风险：** 月度波动率、最大回撤（MDD）和下行偏差。
3. **金融表现：** 夏普比率（E[Returns]/波动率）、索提诺比率（E[Returns]/下行偏差）和卡尔马比率（E[Returns]/MDD）用于衡量风险调整后表现。我们还纳入了平均盈利除以平均亏损（Avg. Profits/Avg. Loss）。
4. **排名表现：** Kendall's Tau、k处归一化折损累计增益（NDCG@k）[36]，后者适用于非二元相关性（评分）指标，同时强调顶部返回结果[13]。我们注意到 k 是一个预定义阈值，本文中设为 k = 100 以覆盖每个多/空组合的大小。

$$r^{\\text{DEC}}_{\\tau_m, \\tau_{m+1}} = \frac{1}{n_{\\tau_m}} \sum_{i=1}^{n_{\\tau_m}} D^{(i)}_{\\tau_m} \frac{\sigma_{\\text{tgt}}}{\sigma^{(i)}_{\\tau_m}} r^{(i)}_{\\tau_m, \\tau_{m+1}} \\tag{12}$$

其中 D^{(i)}_{τ_m} = {0, 1}，对于感兴趣的十分位取值为1，否则为0。我们还在组合层面执行了额外的缩放。参考汇总结果（图4），除随机模型外，所有策略从十分位1到10的收益和夏普比率呈普遍上升趋势，这强调了动量因子的一致性。更重要的是，由于LTR模型能够更精确地将资产放置在适当的十分位中，这些指标上升更为陡峭——导致十分位1和十分位10组合之间的收益差异更大。各策略十分位组合收益的图示（图5）巩固了这一观察，展示了模型排名能力与收益流分散度之间的联系。这种关系在LTR模型组中最为明显，与前述统计数据相呼应，从而验证了我们关于更好资产排名改善策略表现的假设。

## VI. 结论

以横截面动量作为示范性用例，我们引入学习排序算法作为排列资产的新方法，这是横截面系统化策略所需的重要步骤。此外，支撑这些算法的模块化框架允许灵活地纳入额外的特征输入——为更广泛的横截面策略集提供了可推广的平台。通过学习启发式和先回归后排序方法仅表面捕获的资产间关系（成对或列表级）结构，我们获得了跨工具更准确的排名。这转化为夏普比率相对于传统方法约三倍的提升，以及在表现和排名质量相关指标上的明显且显著的改善。

未来工作的方向包括在架构或模型集成方面的创新以进一步提高策略表现，以及研究这些排序技术在更高频数据（如订单簿）和资产类别上的有效性。

## VII. 附录

### A. 横截面动量的学习排序

学习排序（LTR）是一个涉及训练和测试阶段的监督学习任务。文档检索是使LTR框架具体化的标准问题设置，我们遵循这一惯例。

![Exhibit 6: Learning to Rank for Cross-Sectional Momentum](https://github.com/wangzhe3224/quantpaper-repo/blob/main/2012.07149v1/images/page11_img1.png)

*图6：横截面动量的学习排序。*

对于训练，我们提供一组查询 Q = {q_1, ..., q_m}。每个查询 q_i 关联一个文档列表 d_i = {d^{(1)}_i, ..., d^{(n_i)}_i}，其中 n_i 是 q_i 的文档总数，以及一组伴随的文档标签 y_i = {y^{(1)}_i, ..., y^{(n_i)}_i}，标签代表等级。设 Y = {Y_1, ..., Y_ℓ} 为标签集，对于 ∀ i, j，有 y^{(j)}_i ∈ Y。我们还有 Y_ℓ ≻ Y_{ℓ−1} ≻ ... ≻ Y_1，其中 ≻ 代表序关系——给定文档上的更高等级意味着该文档相对于其查询具有更强的相关性。对于每个查询-文档对，可以形成特征向量 x^{(j)}_i = φ(q_i, d^{(j)}_i)，注意 φ(·) 是特征函数，i ∈ {1, ..., m}，j ∈ {1, ..., n_i}。设 x_i = {x^{(1)}, ..., x^{(n_i)}，我们可以组装训练集 {(x_i, y_i)}^m_{i=1}。LTR的目标是学习一个函数 f，当给定样本外输入 x^{(i)}_{m+1} 时，预测分数 f(x^{(i)}_{m+1}) = z^{(i)}_i。更多细节请参阅[10]。

将上述框架转置到动量策略中，我们可以将每个查询类比为组合再平衡事件，而关联的文档及其伴随标签可以分别被视为资产及其在下一次再平衡时基于某种表现指标（通常取收益）分配的十分位。图6提供了这种适配的示意图，我们进一步加以具体化。对于训练，设 B = {b_1, ..., b_{m−1}} 为一系列月度再平衡，其中在每个 b_i 处，我们有一组股票工具 e_i = {e^{(1)}_i, ..., e^{(n_i)}_i} 和分配的十分位集合 δ_{i+1} = {δ^{(1)}_{i+1}, ..., δ^{(n_i)}_{i+1}}，其中对于 ∀ i, j，有 δ^{(j)}_{i+1} ∈ D = {D_1, ..., D_{10}}。类似地，对于 k, l ∈ {1, ..., 10}，k > l ⇒ D_k ≻ D_l。对于每个再平衡-资产对，我们可以形成特征向量 u^{(j)}_i = φ(b_i, e^{(j)}_i) 以及更广泛的训练集 {(u_i, δ_{i+1})}^{m−1}_{i=1}，其中 u_i = {u^{(1)}_i, ..., u^{(n_i)}_i}。注意可以为 u^{(j)}_i 纳入其他特征——允许开发不同类型的横截面策略。在区间 m 处，给定由学习系统产生的已训练函数 g 的测试特征向量集，我们在分数计算阶段计算分数集 g(u_m)，然后按照第III-A节的指示构建多/空组合。
