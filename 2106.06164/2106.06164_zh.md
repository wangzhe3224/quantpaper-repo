## 摘要

由于被称为星期效应的日历异象，股票市场可能变得缺乏效率。日历异象在金融文献中已有广泛研究，但从经济物理学角度对其进行探索仍然不足。

本文使用多重分形分析来评估市场收益的时间动态是否也表现出日历异象，如星期效应。我们将多重分形去趋势波动分析（MF-DFA）应用于全球市场指数的每日收益数据，分别针对每周各天进行分析。研究结果表明，每周各天具有不同的多重分形特征。周一收益倾向于表现出比其他日期收益更强的持续行为和更丰富的多重分形结构。对序列进行随机重排后分析发现，多重分形性既源于较宽的概率密度函数，也源于长期相关性。通过时间依赖的多重分形分析，我们发现金融危机期间周一收益的多重分形谱比其他日期宽得多。市场收益多重分形动态中存在星期效应，这为从经济物理学视角进一步研究日历异象提供了动力。

**关键词：** 日历异象，星期效应，市场指数，多重分形去趋势波动分析

## 1. 引言

根据有效市场假说（EMH）[1, 2]，在任何时点，市场价格都应包含并反映所有可用信息。然而，许多研究 [3, 4, 5, 6] 表明，金融市场经常变得缺乏效率，其行为不再遵循随机游走的规律。股票市场反而可能以异象的形式偏离有效市场假说的规则。异象可大致分为日历异象、基本面异象和技术异象 [7]。研究最为广泛的定价异象是日历异象或季节性异象，它们代表证券收益在某些日历时间点附近的系统性模式。日历异象包括星期效应 [8]、月末效应 [9]、年初效应 [10] 和节假日效应 [11]。星期效应是指股票在某特定天表现出显著高于一周中其他天收益的倾向。Cross [12] 首先在标准普尔指数上提供了星期效应的证据——研究发现周一的价格收益显著为负。此后，这一现象得到了广泛研究，并在其他金融市场被发现，如股票市场 [13, 14, 15]、汇率 [16, 17]、债券 [18]、原油 [19]、黄金 [20] 和加密货币 [21]。关于季节性异象的详细综述，读者可参阅文献 [22] 和 [23]。

金融市场也引起了相关领域研究者的极大关注，例如经济物理学。经济物理学通过借鉴统计物理学中的分形和多重分形 [24, 25, 26, 27]、信息论 [28, 29] 和网络结构 [30, 31, 32] 等概念，为理解金融市场开辟了新视角（参见文献 [33] 及其中的参考文献以获取全面综述）。虽然文献中关于一系列金融市场（包括市场指数、股票、汇率和大宗商品）的许多著名结论可以归功于经济物理学，但仍有一些重要现象有待从该视角进行考察。据我们所知，日历异象就是这样一个尚未被发掘的现象，本研究旨在为此方向做出贡献。

本文使用多重分形分析来评估市场收益的时间动态是否表现出日历异象，如星期效应。我们将多重分形去趋势波动分析（MDFA）[34] 应用于全球市场指数的每日收益数据，分别针对每周各天（周一收益、周二收益等）进行分析。然后比较所得多重分形谱的性质，以揭示底层随机过程的显著行为差异。经济学文献指出，对于某些市场，随着市场变得更加有效，这种效应会消失 [35, 36]。为了随时间观察这一行为，我们使用滑动窗口对美国（GSPC）市场进行了时间依赖的多重分形分析，计算收益序列的多重分形谱。这种新颖的方法使我们能够分析与市场波动不同特性相关的多重分形参数的时间演变，从而更好地理解底层的随机过程。本文结构如下：第2节介绍MF-DFA和时间依赖方法；第3节描述市场数据；第4节展示结果和讨论；第5节得出结论。

## 2. 方法

分形过程的特征是由单一标度指数描述的长期相关性，而在多重分形时间序列中，大小波动子集可能具有不同的标度行为，对长期相关性的分析会产生标度指数的层级结构 [34]。时间序列的多重分形分析可以使用不同的方法进行，如小波变换模极大值（WTMM）方法 [37]、多重分形去趋势波动分析（MF-DFA）方法 [34] 和多重分形去趋势移动平均方法（MF-DMA）[38]。本文采用MF-DFA，该方法已被证明能产生可靠的结果 [39]，并已广泛用于分析生理信号 [40, 41, 42]、地球物理数据 [43]、天气数据 [44] 和金融时间序列 [45]。

MF-DFA算法的实现可描述如下 [34]。

**i.** 第一步是对原始序列 $x(i)$，$i = 1, \ldots, N$ 进行积分，得到

$$X(k) = \sum_{i=1}^{k} [x(i) - \langle x \\rangle], \quad k = 1, \ldots, N, \\tag{1}$$

其中 $\langle x \\rangle = \frac{1}{N}\sum_{i=1}^{N} x(i)$ 为均值。

**ii.** 接下来，将积分序列 $X(k)$ 分为 $N_n = \\text{int}(N/n)$ 个长度为 $n$ 的非重叠段，在每个段 $\nu = 1, \ldots, N_n$ 中，通过线性或更高阶多项式最小二乘拟合估计局部趋势 $X_{n,\nu}(k)$，并从 $X(k)$ 中减去。

**iii.** 计算每个段去趋势后的方差

$$F^2(n,\nu) = \frac{1}{n} \sum_{k=(\nu-1)n+1}^{\nu n} [X(k) - X_{n,\nu}(k)]^2 \\tag{2}$$

然后对所有段求平均，得到 $q$ 阶波动函数

$$F_q(n) = \left\{ \frac{1}{N_n} \sum_{\nu=1}^{N_n} [F^2(n,\nu)]^{q/2} \\right\}^{1/q}, \\tag{3}$$

其中，一般而言，$q$ 可以取除零以外的任何实数值。

**iv.** 对所有窗口大小重复此计算，可以得到波动函数 $F_q(n)$ 与窗口大小 $n$ 之间的关系。如果存在长期相关性，$F_q(n)$ 随 $n$ 按幂律 $F_q(n) \sim n^{h(q)}$ 增长。标度指数 $h(q)$ 通过 $\log F_q(n)$ 对 $\log n$ 线性回归的斜率获得。

幂律指数 $h(q)$ 被称为广义赫斯特指数，对于平稳时间序列，$h(2)$ 等同于著名的赫斯特指数 $H$。对于正的 $q$ 值，$h(q)$ 描述大波动的标度行为；对于负的 $q$ 值，$h(q)$ 描述小波动的标度行为。对于单分形时间序列，$h(q)$ 与 $q$ 无关；对于多重分形时间序列，$h(q)$ 是 $q$ 的递减函数。

广义赫斯特指数与基于标准配分函数的多重分形形式化所定义的Renyi指数 $\tau(q)$ 相关：$\tau(q) = qh(q) - 1$。对于单分形信号，$\tau(q)$ 是 $q$ 的线性函数（因为 $h(q) = \\text{const.}$）；对于多重分形信号，$\tau(q)$ 是 $q$ 的非线性函数。多重分形过程还可以通过奇异谱 $f(\alpha)$ 来刻画，$f(\alpha)$ 通过勒让德变换与 $\tau(q)$ 相关：

$$\alpha(q) = \frac{d\tau(q)}{dq}, \\tag{4}$$

$$f(\alpha(q)) = q\alpha(q) - \tau(q), \\tag{5}$$

其中 $f(\alpha)$ 是测度中具有Lipschitz-Holder指数 $\alpha$ 的奇异点支撑的分形维数。单分形信号的奇异谱在 $f(\alpha)$ 平面上表示为一个单点，而多重分形过程则产生一个单峰函数。

多重分形谱反映了底层随机过程的复杂程度，可以通过以下三个参数来刻画。奇异谱被拟合为四次多项式：

$$f(\alpha) = A + B(\alpha - \alpha_0) + C(\alpha - \alpha_0)^2 + D(\alpha - \alpha_0)^3 + E(\alpha - \alpha_0)^4 \\tag{6}$$

多重分形谱参数确定为：最大值位置 $\alpha_0 = \arg\max_\alpha f(\alpha)$、谱宽度 $W = \alpha_{\max} - \alpha_{\min}$（通过将拟合曲线外推至零获得），以及偏度参数 $r = (\alpha_{\max} - \alpha_0)/(\alpha_0 - \alpha_{\min})$，其中 $r = 1$ 表示对称形状，$r > 1$ 表示右偏形状，$r < 1$ 表示左偏形状。这三个参数可用于评估底层过程的复杂性。$\alpha_0$ 的小值意味着过程具有相关性且外观更加规则。谱宽度 $W$ 衡量过程的多重分形程度——分形指数范围越宽意味着结构越"丰富"。偏度参数 $r$ 指示哪种分形指数占主导地位：如果高指数占主导，则 $f(\alpha)$ 谱右偏（$r > 1$），过程以"精细结构"（小波动）为特征；如果低指数占主导，则过程更加规则或平滑，$f(\alpha)$ 谱左偏（$r < 1$），分形指数描述大波动的标度行为。总之，具有高 $\alpha_0$ 值、宽分形指数范围 $W$（更高程度的多重分形性）和右偏形状（$r > 1$）的信号可能被认为比具有相反特征的信号更加复杂 [42]。

时间序列中多重分形性的两个来源是：(i) 时间序列值的较宽概率密度函数，以及 (ii) 大小波动的不同长期相关性。多重分形的类型可以通过随机重排序列并分析其行为来确定。对于类型 (ii) 的多重分形，重排序列表现出简单的随机行为（因为长期相关性被破坏），$f(\alpha)$ 谱宽度缩小为一个单点；对于类型 (i) 的多重分形，$f(\alpha)$ 谱宽度保持不变（因为概率密度无法被消除）；对于同时具有类型 (i) 和 (ii) 的多重分形，重排序列表现出比原始序列更弱的多重分形性 [34]。
