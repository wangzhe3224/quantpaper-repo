# 系统化投资中的 ChatGPT：利用大语言模型提升风险调整收益

**作者：** Nikolas Anic, Andrea Barbon, Ralf Seiz, Carlo Zarattini

**发表时间：** 2025年10月 (arXiv:2510.26228v1)

---

## 亮点

- **Alpha 思路**：大语言模型（LLM）可通过解读公司层面新闻来增强横截面动量策略，以此调节选股和组合权重。
- **数据来源**：Finreon 内部数据集（类似 CRSP 的日收益率）、Stock News API（秒级精度时间戳）、FRED（无风险利率）。
- **股票池**：标普500成分股。
- **样本期间**：2019年10月至2025年3月（验证集：2019年10月–2023年12月；测试集：2024年1月–2025年3月）。
- **核心发现**：LLM增强动量策略的样本外夏普比率为1.06，基准为0.79；年化收益率30%对24%。
- **信号构建**：使用 ChatGPT 4.0 mini 对公司新闻评分（0–1，归一化至 $-1$ 到 $+1$），在前两分位动量候选股中进行排名和权重倾斜。

---

## 摘要

本文研究大语言模型（LLM）能否通过从公司层面新闻中提取预测信号来改善横截面动量策略。我们将标普500成分股的日度美国股票收益与高频新闻数据相结合，使用经过提示工程设计的 ChatGPT 查询，告知模型某只股票即将进入动量组合。LLM 评估近期新闻是否支持过去收益的延续，生成用于调节选股和组合权重的评分。LLM增强动量策略优于标准多头动量基准，在样本内和模型预训练截止日期之后的真正样本外期间均实现了更高的夏普比率和索提诺比率。这些收益在交易成本、提示设计和组合约束方面具有稳健性，且在集中、高确信度的组合中表现最强。结果表明，LLM 可以作为金融新闻的有效实时解释器，为既有的因子投资策略增加增量价值。

**关键词：** 大语言模型、动量投资、文本分析、新闻情绪、人工智能

## 1 引言

大语言模型（LLM）已在从法律文件分析到医疗诊断和客户服务自动化等多个领域展示了其实用性。然而，在金融财富管理领域，关于 LLM 有效性的实证证据仍然稀缺。许多研究将因子异象（尤其是动量）的存在与公司基本面新闻的发布以及此类信息逐步纳入价格联系起来。文献表明，投资者在短期内对新闻反应不足，导致可预测的价格漂移，这可以通过动量策略加以利用。例如，盈余公告后漂移和其他对公开披露的延迟反应突显了信息处理摩擦如何创造收益可预测性的机会（Bernard and Thomas, 1989）。基于这一直觉，我们假设 LLM 实时解释和综合文本信息的能力可用于识别可能引发价格调整的新闻。进而，这应有助于更好地预测观察到的正过去收益是否可能由动量驱动并在近期延续。这引出了如下猜想：将传统动量信号与从公司特定新闻中提取的 LLM 驱动洞察相结合，可以形成更明智且潜在表现更好的动量组合。

因此，本文探讨 LLM 是否可以通过从公司特定新闻中提取信号来增强因子交易策略，更具体地说是动量策略。为了实证检验我们的猜想，我们整合了多个高频信息源的新数据集。首先，我们利用日度频率的美国股票收益历史数据集，计算标准横截面动量信号并评估交易策略随时间的表现。该数据集为衡量基线动量效应和基准检验 LLM 信号纳入所带来的改善提供了基础。

其次，我们从 Stock News API 获取了具有分钟级时间戳的细粒度公司新闻数据库。这种精细的时间分辨率对于将新闻内容与市场反应对齐并分离新闻事件的即时信息影响至关重要。通过关注公司层面的披露和事件，而非更广泛的宏观经济头条，我们旨在捕捉可能在个股层面推动动量的具体叙事。

第三，我们应用提示工程技术与 OpenAI 开发的最先进 ChatGPT 模型进行交互。这些提示经过精心设计，从每篇新闻文章的文本中提取语义信号，如其与公司的相关性，以及新闻是否可能加强或 contradict 现有价格趋势。重要的是，提示明确告知 LLM 所考虑的股票即将进入基线动量组合，从而在潜在交易决策的背景下构建分析。这使模型能够在预期过去收益延续的背景下评估新闻，增强其检测支持或挑战动量假设的信号的能力。这一 LLM 驱动的解释层使我们能够构建一个动态信号，用从同期文本数据中提取的洞察来增强传统动量指标。

第四，我们聚焦于基于一个简单但成熟的技术信号的交易策略：横截面动量。股票根据其在固定回溯窗口内的过去收益进行排名，并相应地建立头寸。然后，我们通过根据公司特定新闻的 LLM 生成信号来调节组合权重来丰富这一策略。这种设计使我们能够直接评估大语言模型对新闻内容的实时解释能否改善动量策略的信息效率和表现。

我们的实证发现支持将基于 LLM 的洞察纳入动量策略的价值。LLM 增强动量组合在样本内和样本外均持续优于基线策略，在风险调整收益方面提供了经济上显著的改善。即使考虑了2个基点的保守交易成本估计，这些表现改善仍然稳健。

我们发现月度再平衡频率的显著优于周度。这可能是由较低的换手率和减少的交易成本驱动的，这些因素对高频策略的影响尤为突出。此外，由于预训练截止日期，所使用的 LLM 的时间不一致性似乎并未夸大表现。相反，当我们仅关注模型训练数据结束后的期间时，结果甚至更强。这表明模型解读新闻的能力依赖于其通用语言理解能力，而非记忆的历史内容。

我们还比较了不同的提示表述，发现更简单的提示略有更好的表现，尽管差异不具有统计显著性。重要的是，对组合权重应用分散化约束会略微降低夏普比率，但在风险管理方面带来实质性改善。这表明原始 LLM 驱动信号倾向于产生过度集中的头寸，可以通过适当的组合构建技术加以缓解。

最后，我们记录了表现如何随组合规模变化的关键差异。我们发现 LLM 增强策略在应用于较小的高确信度信号集时表现更好。这表明 LLM 的信息优势在识别对新闻特别敏感的机会方面最为突出，而非提供广泛的横截面覆盖。

### 1.1 相关文献

本文基于三个主要文献方向：关于动量和市场反应不足的大量研究、金融文本分析领域日益增多的工作，以及大语言模型（LLM）在资产定价和投资策略中的新兴应用。

实证资产定价的基础文献记录了动量利润的存在，即近期表现强劲的股票倾向于在近期内继续表现优异（Jegadeesh and Titman, 1993; Chan et al., 1996）。多项研究将这些收益模式归因于公司特定信息事件后的延迟价格调整，表明投资者在短期内对新闻反应不足（Bernard and Thomas, 1989; Hong and Stein, 1999）。这种反应不足导致收益可预测性，特别是在盈余公告和其他公开披露周围。在此基础上，横截面动量策略利用跨股票的价格趋势，通常假设信息随时间逐步纳入价格。

平行文献探讨了将文本数据作为金融市场预测信号来源的使用。早期贡献者研究新闻文章、盈余报告和新闻稿的情绪内容来解释资产价格变动（Tetlock, 2007; Loughran and McDonald, 2011）。自然语言处理（NLP）的进步使得能够从非结构化文本中更复杂地提取基于情绪和主题的信号（Nassirtoussi et al., 2014; Ke et al., 2019）。最近的研究将新闻分析整合到资产定价模型中，表明基于文本的信号和机器学习模型可以补充传统的收益预测因子（Gu et al., 2020）。

最近，GPT-3 和 GPT-4 等大语言模型为实时文本分析开辟了新途径。虽然先前的 NLP 方法通常依赖关键词词典、情绪评分或有监督分类器，但 LLM 提供了一个灵活的零样本接口，用于从非结构化文本中提取细微信息。越来越多的研究探索了 LLM 在经济和金融应用中的潜力，包括预测、决策支持和情绪提取（Lopez-Lira and Tang, 2023; Kim et al., 2024）。然而，很少有论文研究了 LLM 是否能改善系统化投资中的因子策略。值得注意的是，Lopez-Lira and Tang (2023) 表明 ChatGPT 可以预测市场对新闻标题的反应，但在横截面策略中的应用仍然有限。

本文通过评估经过提示工程的 LLM 能否通过大规模解读公司新闻来增强动量投资，为这一新兴文献做出贡献。我们是最早测试将 LLM 生成的洞察整合到实时组合构建中的人之一，在横截面资产定价框架中评估此类信号的经济价值。

## 2 方法论

我们首先复制 Jegadeesh and Titman (1993) 和 Carhart (1997) 中概述的经典横截面动量策略，每月根据过去12个月的收益（排除最近一个月）对股票进行排序，并通过买入前两个分位构建多头组合。我们专注于多头部分，以更好地反映实际投资约束和机构惯例。此外，我们包括前两个分位以确保与 LLM 组合构建的性能可比性。为确保流动性和聚焦于可实施的组合，我们将股票池限制为标普500指数成分股。这一焦点有助于更清晰地实施策略，避免因流动性差的小盘股造成的偏差，并与机构资产管理人通常考虑的投资范围保持一致。

然后，我们使用 LLM 模型生成的信号来修改动量组合的构成。为了创建这些信号，我们向 LLM 输入与更广泛的动量候选集（即基于过去收益的前两个分位，而非仅前一个分位）相关的公司特定新闻。LLM 被提示评估每只股票是否应被纳入或排除在最终动量组合之外。此外，我们允许根据 LLM 信号的强度来调节组合权重。完整的方法论在以下小节中详细说明，并在图1中进行了可视化总结。

### 2.1 数据来源

我们的实证分析结合了三个不同的数据集，各自在构建和评估 LLM 增强动量策略中发挥着特定作用。

首先，我们使用 Finreon 内部数据集，其结构和覆盖范围与 CRSP 数据库类似，提供美国股票的日度总收益和市值数据。该数据集构成了计算基线动量信号、应用流动性和指数成员筛选以及实施组合构建的骨干。

其次，我们从 Stock News API 获取高频公司新闻。该数据集包含具有秒级精度的发布时间戳，使新闻项目与盘中市场活动的精确对齐成为可能。对于每个新闻项目，我们记录文章标题、内容简短摘要和发布来源。新闻来源于 CNB C、Zacks、Bloomberg、The Motley Fool、Fox Business 和 The Street 等知名媒体。聚焦于公司层面的新闻使我们能够隔离最可能驱动短期价格调整的信息事件。

第三，我们从联邦储备经济数据（FRED）数据库获取美国无风险利率。无风险利率序列用于计算超额收益以进行组合表现评估，并确保风险调整表现指标的一致性。

### 2.2 LLM 增强动量组合

在每个月末，我们首先识别将在下个月进入基线多头动量组合的股票。具体而言，我们考虑过去12个月收益（排除最近一个月）中前一个分位的股票。为了扩大 LLM 评估的覆盖范围，我们将该集合扩展至包括第二个分位的股票，形成更广泛的动量候选池。

对于该扩展集中的每只股票，我们在收盘前不久收集新闻数据。我们收集从前 $k$ 个交易日（$t - k$）的15:45到当日（$t$）15:45发布的所有新闻文章，其中回溯期 $k$ 是需要优化的参数。每个股票-交易日对的这组新闻随后使用自定义设计的提示由大语言模型（LLM）处理。提示执行三个关键功能：描述基线动量策略的逻辑、告知模型该股票已基于动量标准被选中、并请求一个反映该股票在近期继续表现良好的可能性的评分。LLM 输出0到1之间的评分，代表其基于新闻内容的评估。评分随后归一化至 $-1$ 到 $+1$ 之间。

扩展集中的股票随后根据其 LLM 评分进行排名。在多只股票获得相同评分的情况下，使用原始动量排名来打破平局。从这个最终排名列表中，选择前 $m$ 只股票组成增强组合。参数 $m$ 被视为超参数并需优化。

最初，所有被选中的股票被分配基线权重，而基线加权策略为等权或市值加权。为了将 LLM 信号的强度纳入配置，我们随后根据每只股票的评分来倾斜这些权重。股票 $i$ 的最终权重 $W_i$ 计算如下：

$$W_i = E \cdot \eta \cdot \text{LLM\_Score}_i$$

其中 $E$ 是基线权重，$\text{LLM\_Score}_i$ 是股票 $i$ 的归一化评分，$\eta$ 是需要优化的缩放参数。在为所有股票 $i$ 计算 $W_i$ 后，权重被标准化为总和为一。这一过程使 LLM 能够同时影响选股和资本配置，为传统动量策略增加了一层信息驱动的优化。

### 2.3 样本分割与超参数选择

为了以稳健和现实的方式评估 LLM 增强动量策略的表现，我们将包含1,382个日度观测的样本分为两个不同的子样本：覆盖2019年10月至2023年12月的**验证集**和跨越2024年1月至2025年3月的**测试集**。表1总结了两个期间并报告了每个子集的日度观测数。

| 子样本 | 起始 | 结束 | 长度 | 观测数 |
|--------|------|------|------|--------|
| 验证集 | 2019年10月 | 2023年12月 | ~4年 | 1070 |
| 测试集 | 2024年1月 | 2025年3月 | 15个月 | 312 |

*表1：验证集和测试集描述*

验证集用于识别 LLM 增强策略的最佳超参数配置。具体而言，我们在候选值网格上搜索 LLM 回溯窗口 $k$、前瞻窗口 $l$、选股数量 $m$ 和基于评分的加权乘数 $\eta$ 等参数。此外，参数还包括第2.4节中描述的提示类别 $\pi$、再平衡频率 $\tau$（月度或周度）、指定是否对每只股票施加最大15%权重约束的布尔变量 $c$、指示初始加权方案为等权或市值加权的虚拟变量 $w$，以及组合中包含的股票数量 $m$。对于每个参数组合 $\theta = (\tau, k, l, m, \pi, c, w, \eta)$，我们计算组合收益并评估以下目标函数：

$$U(\theta) = \frac{3}{4} \cdot \text{Sharpe}(\theta) - \frac{1}{4} \cdot \text{MDD}(\theta) \quad (1)$$

其中 $\text{Sharpe}(\theta)$ 和 $\text{MDD}(\theta)$ 分别代表所有评估参数集中夏普比率和最大回撤的百分位排名（0到1之间）。这一公式对风险调整表现赋予更大权重，同时对下行风险进行惩罚。我们的发现在目标函数的替代加权下定性稳健。一旦基于验证数据确定了最优参数集 $\theta^*$，我们在测试集上评估其样本外表现。这一过程提供了对未来策略表现的现实估计，模拟了模型和参数预先固定的情况。因此，测试集结果不受对过去数据过拟合的影响。

重要的是，我们的设置不需要专用的"训练集"，因为所使用的语言模型 ChatGPT 4.0 mini 已经过预训练。我们不对模型进行任何微调，主要原因是我们的数据集规模相对有限。尽管如此，将任务特定微调纳入考虑代表了未来研究的一个有趣方向。在我们的实现中，模型被视为文本输入的静态黑盒解释器，其参数在整个研究过程中保持固定。

此外，由于 ChatGPT 4.0 mini 仅基于截至2023年10月的数据进行训练，测试集（从2024年1月延伸至2025年3月）相对于模型自身的知识库处于真正的样本外状态。特别是，2023年11月之后的结果可以保证免受通过模型预训练产生的任何形式的信息泄漏。虽然 He et al. (2025) 表明信息泄漏在金融预测任务中是有限的，但我们的方法使评估特别严格，它分离了模型从训练数据中泛化的能力，而非依赖记忆的历史信息。

### 2.4 提示设计

我们应用提示工程技术与 OpenAI 开发的最先进 ChatGPT 模型进行交互。每个提示的目标是从一系列公司新闻项目中提取信息性信号，指示该股票是否可能延续其近期价格趋势。为此，提示明确告知模型所讨论的股票即将进入动量组合，从而将分析构建为前瞻性投资决策。通过这样做，模型被鼓励在动量延续的背景下评估新闻的内容和语调，识别近期信息是支持还是 contradict 过去收益所暗示的趋势。

我们构建了两种在复杂性和结构上不同的提示类别：**基础提示**和更**高级**的提示。基础提示简要提及基线动量策略，并提供简洁的任务描述，聚焦于最终目标，即预测收益延续的可能性。它包含关于组合形成过程的最少上下文，不对新闻流施加任何显式结构。目标是评估更轻量的表述是否仍能从模型生成有用的信号。高级提示则提供了更详细和结构化的表述。它明确解释了基线动量组合的形成方式、描述了预测时间范围，并概述了模型应如何解读新闻项目。特别是，它提供了关于可能对预测价格延续相关的信息类型的建议，并描述了提示中提供的新闻流的组织方式。

所有提示都是动态生成并针对特定股票和评估上下文量身定制的。具体而言，每个提示取决于：(i) 所考虑的股票代码，(ii) 用于收集新闻的回溯窗口 $k$，以及 (iii) 动量信号的预测时间范围。在每个提示的末尾，附加了前 $k$ 个交易日内发布的公司新闻文章列表。对于每篇文章，我们包括标题、简短摘要以及自发布以来经过的时间，以相对于请求时间戳表示。这种格式使模型能够同时考虑新闻的内容和新近度。预测时间范围是再平衡频率的函数：周度再平衡为5天，月度再平衡为21天。

**基础提示示例：**

> **---- 简介 ----**
>
> 你是一个金融分析模型，负责基于动量信号和每只股票的新闻驱动情绪评分来构建和再平衡标普500多头组合。

## 3 实证结果

本节报告论文的主要实证发现。我们首先报告策略组件和 LLM 生成信号的描述性统计。这为用于构建和评估 LLM 增强动量组合的底层数据提供了描述性视角。接下来，我们比较 LLM 增强策略与基线动量组合的表现。我们记录了使用验证集选择的优化超参数集，并检查策略随时间的行为，重点关注样本内和样本外期间。表现指标以日度频率评估，以提供收益动态的高频视角。最后，我们进行详细的参数分析，研究策略表现如何随关键超参数的不同选择而变化。

### 3.1 描述性统计

图2提供了一组描述性统计，描述了我们的数据集和策略输入的关键组成部分。面板(a)显示了2019年至2024年每年发布的新闻文章总数。数据显示出明显的上升趋势，年度新闻量从2019年的不足10万条增加到2024年的超过20万条。这种增长反映了公司新闻覆盖范围的改善和自动化金融媒体活动的增加。这一上升趋势强化了可扩展自动化实时新闻处理方法在资产管理中的相关性。

面板(b)呈现了每个公司-年度的公司新闻文章数量分布。x轴以对数刻度显示。如预期，分布严重右偏：虽然中位数公司每年收到几百篇文章，但少数知名公司吸引了数千篇。这种偏斜突显了超大市值公司获得的不成比例的媒体关注，并强调了能够处理跨横截面不平衡文本输入的模型的重要性。

面板(c)显示了基线多头动量组合的日收益分布。分布大致对称且中心接近零，肥尾捕捉了大幅正收益日和负收益日的存在。这种形状与日度股票收益的已知特性一致，即使在应用了动量等系统性筛选后也是如此。

面板(d)报告了股票-日级别 LLM 生成评分的分布。这些评分是通过对每只股票的新闻流应用基础提示获得的，并归一化至 $-1$ 到 $+1$ 之间。为了简化可视化，图中排除了因特定日期缺乏相关新闻而缺失的评分。在实际实证分析中，这些缺失评分被视为零，反映了在缺乏新信息时的中立立场。分布在横截面和时间上表现出显著变化，这对于生成差异化的交易信号至关重要。

综上所述，这些描述性统计确认了文本数据集的丰富性和异质性，以及 LLM 生成评分作为系统性投资策略条件信号的合理性。

### 3.2 最优超参数

我们首先使用验证集识别最优超参数配置，然后评估所得策略在样本内和样本外的表现。在验证集上共测试了512组超参数组合 $\{\theta_i\}_{i=1,...,512}$。对于每个组合 $\theta_i$，评估目标函数 $U(\theta_i)$，并根据该指标选择表现最佳的模型。表2总结了每个参数的可能值及由此产生的最优参数集 $\theta^*$。

| 符号 | 参数 | 选项 | 最优值 |
|------|------|------|--------|
| $\tau$ | 再平衡频率 | 日、月 | 月 |
| $k$ | 回溯窗口 | 1天、5天 | 1天 |
| $l$ | 前瞻窗口 | 1天、21天 | 21天 |
| $\pi$ | 提示类型 | 基础、高级 | 基础 |
| $m$ | 股票数量 | 25、50、75、100 | 50 |
| $c$ | 权重约束 | 是、否 | 是 |
| $w$ | 初始加权方案 | 等权、市值加权 | 市值加权 |
| $\eta$ | 权重乘数 | 1.25、2.5、3.75、5 | 5 |

*表2：在验证集上选择的最优超参数配置*

最优策略每月再平衡（$\tau = \text{月}$），反映了对新信息响应性和交易成本效率之间的权衡。新闻检索的回溯窗口设为1天（$k = 1$），表明最近的公司新闻对短期收益延续具有最强的预测能力。前瞻窗口设为21天（$l = 21$），尽管不同前瞻时间范围的预测质量没有显著差异。每月选择的最优股票数为 $m = 50$，表明 LLM 增强信号在应用于相对集中的高确信度头寸时最为有效。

表现最佳的提示是两种替代方案中较简单的一种（$\pi = \text{基础}$），表明简洁的任务描述足以在此环境中从模型提取有用信号。初始配置为所选股票间的市值加权（$w = \text{市值加权}$），表明 LLM 增强组合的表现可以在模型建立在大公司更强信息基础之上时得到最佳发挥。这具有一定直觉合理性，因为较大的公司通常产生更多的新闻覆盖和市场评论，为 LLM 提供了从中提取信号的更丰富数据输入。此外，LLM 评分使用 $\eta = 5$ 的乘数来倾斜这些权重。这个相对较高的乘数表明 LLM 评分的横截面变化是有意义的，可以自信地用于资本配置。

总体而言，最优配置反映了纪律化的实施、对最新新闻的关注，以及在多元化但精选的组合中对强确信度信号的强调。

### 3.3 LLM 增强策略的表现

LLM 增强动量策略与自然基准——基线动量组合——进行评估比较。两种策略在第2节中描述。为确保可比性，两个组合的基线范围和再平衡频率相同，使表现差异完全归因于 LLM 模型的选择（排名）和配置（倾斜）效应。

表3报告了全样本和样本外期间的主要表现统计。

| 指标 | 基准（全样本） | LLM增强（全样本） | 基准（样本外） | LLM增强（样本外） |
|------|----------------|-------------------|----------------|-------------------|
| 夏普比率 | 0.57 | 0.69 | 0.79 | 1.06 |
| 索提诺比率 | 0.54 | 0.69 | 0.93 | 1.28 |
| 收益率 | 15% | 18% | 24% | 30% |
| 波动率 | 26% | 24% | 24% | 22% |
| 最大回撤 | -33% | -31% | -19% | -17% |
| 换手率 | 0.62 | 0.90 | 0.48 | 0.80 |

*表3：假设2个基点交易成本下，基线和LLM增强动量策略在全样本和样本外期间的表现统计。夏普比率和索提诺比率、收益率和波动率均为年化值。*

在全样本评估中，LLM 增强组合的夏普比率为0.69，而基线为0.57。索提诺比率从0.54改善至0.69。年化收益率从基线的15%增加到 LLM 增强版本的18%。波动率从26%略微下降至24%，最大回撤从 $-33\%$ 改善至 $-31\%$。如预期，表现改善以更大的换手率为代价，表明 LLM 增强策略产生更高的交易活动。然而，由于所有报告的结果均扣除交易成本，增加的换手率被更强的预测信号所抵消。

在2024年1月开始的样本外期间，改善更为显著。夏普比率从基线的0.79改善至 LLM 增强策略的1.06，索提诺比率从0.93增加至1.28。总收益率从约24%增加至30%，波动率更低（22%对24%），最大回撤更小（$-17\%$ 对 $-19\%$）。换手率结果保持相似，支持了因增加交易频率而产生的额外成本被更强预测信号所抵消的主张。

虽然这些结果令人鼓舞，但鉴于样本外期间有限，应谨慎解读。例如，LLM 增强收益对基线收益的时间序列回归产生了3.26%的正年化 alpha，但该估计仅在10%水平上具有统计显著性。尽管如此，值得注意的是，所有结果均在假设每笔交易2个基点交易成本的情况下计算，考虑到我们样本中标普500股票的高流动性，这是一个保守的估计。

图3绘制了两种策略随时间的累计收益。LLM 增强组合在整个样本中持续优于基线，在2023年后表现出显著的绩效分化。垂直虚线标记了2024年1月样本外期间的开始。这一时期特别重要，因为它始于 ChatGPT 4.0 mini 的2023年10月预训练截止日期之后。因此，LLM 在这一阶段的表现不能归因于从其训练语料库中的记忆或信息泄漏。LLM 增强策略在此期间持续大幅优于基线的事实支持了如下结论：收益源于模型实时解读新闻和增强动量信号的能力，而非来自预训练阶段嵌入的先验知识。

### 3.4 参数扰动分析

本节我们研究 LLM 增强策略的表现如何随关键参数变化。为此，我们采用受机器学习文献中敏感性分析技术启发的其他条件不变扰动分析（Feurer and Hutter, 2019; Biecek and Burzykowski, 2021）。具体而言，对于每个感兴趣的参数 $p$，我们从第3.2节中确定的最优配置 $\theta^*$ 出发，在所有允许值上变化 $p$，同时将所有其他参数固定在其最优设置。

图4报告了不同参数值下 LLM 增强策略和基线动量组合的年化样本外夏普比率。主要发现如下：

**面板(a)** 表明 LLM 增强策略在月度再平衡频率下的表现显著优于周度，夏普比率分别约为1.1和0.7。这表明较高换手率的成本超过了更频繁信号更新的收益。

**面板(b)** 研究了输入模型的新闻量的影响。将输入窗口从1天扩展到5天仅略微改善了夏普比率。这表明更多新闻不一定转化为更好的信号，因为市场倾向于相当快速地将新信息纳入价格。

**面板(c)** 比较了两种提示类型，揭示基础提示优于高级版本，样本外夏普比率分别约为1.1和0.95。差异不够大以致统计显著，表明两种设计都是可行的。

**面板(d)** 考察了倾斜因子的作用。较高的倾斜因子提高了夏普比率，表明在最终配置中给予 LLM 评分更大权重增强了风险调整收益。虽然改善看起来不大（0.95至1.1），但倾斜因子的影响主要受组合设置中施加的权重约束所限制。

**面板(e)** 考虑了组合中的股票数量。LLM 增强策略在集中于25只股票时表现最强，夏普比率约为1.3，随着组合扩展至100只持仓，表现下降。这表明模型的信号对相对较小的股票集最为有效，可能是那些具有清晰且影响性强的新闻流的股票。值得注意的是，当在不预先筛选初始100只股票的情况下形成组合时，夏普比率也大幅提高，证明了 LLM 信号具有足够的独立能力为组合构建增加价值。

**面板(f)** 考察了不同基线加权策略的影响。结果表明，在从基线转向 LLM 增强策略时，市值加权配置下的表现改善最为显著。通过在主导市值加权组合的较大公司上集中更多权重，模型实际上在其信息优势最强的领域获得了更大的影响力。

总体而言，参数分析突显了 LLM 增强在一系列合理配置中的稳健性。当组合更加集中、再平衡频率更低，且提示结构简单但结合了对模型信号的有意义倾斜时，获得最大的收益。

## 4 结论

本文研究大语言模型能否通过纳入公司特定新闻的实时洞察来增强标准横截面动量策略。使用标普500成分股、日度股票收益和高频新闻数据，我们实施了经过提示工程设计的 ChatGPT 4.0 mini 交互，明确告知模型某只股票即将进入动量组合。LLM 然后评估近期新闻是否支持过去收益的延续，生成用于调节选股和组合权重的评分。

我们的实证分析表明，LLM 增强动量策略在样本内和样本外环境中均持续优于其基线对应策略，实现了更高的夏普比率和索提诺比率、更低的波动率和更小的回撤，同时保持可比的换手率。这些改善在保守的交易成本假设、替代提示设计和组合构建约束方面具有稳健性。重要的是，样本外期间始于模型的预训练截止日期之后，确保观察到的收益不能归因于信息泄漏。

这些结果为动量策略中 alpha 来源的文献做出了贡献，表明部分收益溢价源于公司特定信息延迟纳入价格。通过实时处理新闻，LLM 可以提取补充传统基于收益的预测因子的信号，并帮助更有效地利用这些信息摩擦。

我们的研究存在局限性。样本外期间相对较短，限制了统计功效，时间序列回归估计的 alpha 在某些情况下仅在弱显著性水平上显著。分析局限于单个预训练模型和大盘美股宇宙，关于对其他市场、资产类别或流动性较差证券的泛化性问题仍有待研究。

未来研究可以通过探索 LLM 对金融文本的微调或领域适应、整合来自替代数据源的信号，或在多因子组合设置中进行测试来扩展这一框架。随着更多数据的可获得，评估长期表现对于评估 LLM 增强策略的稳定性和可扩展性至关重要。总体而言，我们的发现表明 LLM 不仅是实验性工具，而是现代投资流程中的实用、可扩展组件，能够在既有因子模型之外提供增量价值。
