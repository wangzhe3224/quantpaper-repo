# 第四章：Alpha 设计

**作者：Scott Bender, Yongfeng He**

*来源：Finding Alphas: A Quantitative Approach to Building Trading Strategies, Second Edition. Edited by Igor Tulchinsky et al., WorldQuant Virtual Research Center. © 2020 Tulchinsky et al., WorldQuant Virtual Research Center. Published 2020 by John Wiley & Sons, Ltd.*

---

本章将阐述从原始数据出发设计 alpha 的完整流程。我们将讨论创建 alpha 时需要做出的一些重要设计决策，以及如何正确评估 alpha。在本章末尾，我们将重点讨论 alpha 开发完成并投入生产后可能出现的若干问题。

## Alpha 的数据输入

Alpha 由数据驱动。Alpha 所寻求的优势可能来自识别高质量的公开数据、对数据的卓越处理——或两者兼而有之。一些典型的数据源包括：

- **价格和成交量。** 可以基于这些数据构建技术分析或回归模型。
- **基本面数据。** 通过自动化分析每家公司的关键指标，可以构建换手率通常非常低的 alpha。
- **宏观经济数据**，如 GDP 数字和就业率，其发布会对整个市场产生影响。
- **文本数据**，如联邦公开市场委员会会议纪要、公司公告、学术论文、期刊、新闻或社交媒体。
- **多媒体数据**，尤其是相关的视频或音频。已有成熟的技术来处理此类数据——例如，将音频转换为文本，用于构建模型。

有时数据源并非用于生成方向性信号，而是试图降低预测中的噪声并优化其他 alpha 信号。例如：

- **风险因子模型。** 通过控制风险敞口或消除对某些风险因子的敞口，可以寻求改善 alpha 的表现。
- **关系模型**，例如通常在一定程度上相互关联的金融工具。某些工具可能领先或滞后于其他工具，从而产生潜在的套利机会。

当今，信息呈爆炸式增长，从不断扩展的数据海洋中提取信号变得越来越具有挑战性。解空间是非凸的、不连续的、动态的；好的信号往往出现在最意想不到的地方。我们如何提取这样的信号？通过限制搜索空间并使用寻宝者此前采用的方法：

- 在以往发现的附近搜索。
- 节约资源，避免挖掘过深。
- 使用经过验证的线索来提高发现概率。
- 至少分配一些资源（计算能力）来测试大胆的理论。

## Alpha 的投资范围

设计 alpha 时的一个重要步骤是选择要交易的目标资产集合；这组资产称为 alpha 的**投资范围**（universe）。该范围可以沿一个或多个维度进行限制，例如：

- 资产类别（股票、交易所交易基金、期货、货币、期权、债券等）
- 地区或国家
- 行业或板块
- 个别金融工具

投资范围的选择通常由输入数据的覆盖范围或 alpha 想法驱动，但即使数据覆盖范围更广，也可以针对特定投资范围专门设计和调优 alpha。

## Alpha 的预测频率

创建 alpha 时的另一个重要设计决策是**预测频率**。这定义了 alpha 生成新预测的时间点。

一些典型的频率：

- **Tick 级。** 新预测由市场事件（如交易）触发。
- **日内。** 在一天中多个预定时间点生成预测。
- **每日。** 每天一次预测，其中包含几个典型的子类型：
  - **Delay 1。** 只能使用当前交易日之前可用的数据进行预测。
  - **Delay 0 snapshot。** 可以使用特定时间之前的数据进行预测。
  - **MOO/MOC。** 预测与开盘或收盘竞价挂钩。
- **每周或每月。**

与投资范围的选择类似，此决策通常由输入数据的频率引导。

## Alpha 的价值

Alpha 价值的最终检验标准是它为其所交易的策略增加了多少风险调整后利润。在实践中，这很难精确衡量，因为：

- 没有一个标准的策略可以使用 alpha，而且 alpha 最终将用于的确切策略在其设计时可能尚不清楚。
- 组合中通常存在非线性效应，使得精确归因利润到单个 alpha 变得困难。

尽管如此，我们仍然可以对 alpha 是否会在策略中增加价值做出有用的预测，并可以合理估计 alpha 对策略表现贡献了多少。

## 实用的 Alpha 评估

由于在设计 alpha 时可能不知道目标交易策略，当单独考察一个 alpha 时，我们如何知道它是否有用？或者，当一个 alpha 被修改时，它是否真的得到了改进？要回答这些问题，需要良好的量化指标。

收集交易策略指标的典型方法是运行模拟（即回测）并测量结果的特征，如信息比率。对 alpha 进行类似测量的一种方法是将 alpha 的预测映射到一个交易策略，然后运行这样的模拟。有不同的映射方法，但最简单的是假设 alpha 的预测强度就是交易策略所采取的美元头寸。

这种映射方法的一个问题是，alpha 通常无法单独映射到好的策略，因为它们被设计用来预测收益，而不是产生扣除成本后的盈利交易。解决此问题的一种方法是在模拟中收取降低的交易成本。

一旦构建了模拟，可以获取的一些有用指标包括：

- **信息比率（Information ratio）。** Alpha 收益的均值除以收益的标准差，衡量 alpha 一致性地做出良好预测的程度。将信息比率与观察期长度结合，可以帮助我们确定 alpha 优于随机噪声的置信水平。对于一个经过五年观察期、拟合度低、独特性强的 alpha，1.0 的年化信息比率是合理的。在实践中，alpha 有一定的拟合度且与现有 alpha 有一定相关性，因此信息比率通常略高于此值。
- **利润率（Margin）** 是 alpha 在模拟中获得的利润除以交易量。这反映了 alpha 对交易成本的敏感程度。利润率越高，说明 alpha 受交易成本的影响越小。低利润率的 alpha 除非与策略中的其他 alpha 非常不同，否则不会增加价值。对于平均的日频 alpha，5 个基点的利润率通常是可以接受的。
- **相关性（Correlation）** 衡量 alpha 的独特性，通常通过与 alpha 池中相关性最高的 alpha 进行比较来测量。相关性越低，说明 alpha 越独特，因此越受青睐。对于一个其他特征中等的 alpha，以下最大相关性的解读是合理的：
  - 大于 0.7：太高，除非 alpha 显著优于现有 alpha。
  - 0.5 到 0.7：处于边缘。Alpha 应在其他某些指标上表现卓越。
  - 0.3 到 0.5：一般可接受。
  - 小于 0.3：良好。

上述指标可以更加复杂化。例如，测试 alpha 在流动性好的股票（高成交量股票）和流动性差的股票上是否都有良好的信息比率可能是有用的。如果 alpha 只在流动性差的股票上有预测能力，那么在打算进行大规模交易的策略中其用途可能有限。

## 未来表现

上一节中的所有指标旨在在除了实际预测之外没有其他信息的情况下评估 alpha。然而，额外的信息——例如 alpha 是如何构建的——对于确定 alpha 是否会在未来做出良好预测可能是有用的。归根结底，重要的是 alpha 是否做出可用的未来预测，而不是历史预测。

考虑一个具有高信息比率但通过优化对历史数据没有经济学解释的参数而构建的 alpha。例如，假设 alpha 有 12 个参数，每个月一个（x1...x12），并且 alpha 规则简单地说是在一月份买入所有股票各 x1 美元，二月份买入 x2 美元，以此类推。如果 x1–x12 是在过去一年中优化的，alpha 会在过去一年做出良好的预测，但没有理由认为它们在进入下一年时仍然有效。

一般来说，在观察历史数据后对 alpha 进行的每次优化或改进，都会在一定程度上改善 alpha 的历史表现，并在不同程度上——通常较小的程度——改善其未来表现。Alpha 设计者应特别确保变更预期会改善 alpha 的未来表现，而不仅仅是历史表现。

当对 alpha 的更改在未来预测上产生的改进非常小（甚至为负），而历史预测的改进很大时，alpha 正在对历史数据进行过度拟合。Alpha 设计者可以通过查看 alpha 在未用于 alpha 构建的数据（样本外数据）上的表现，并将其与用于改进 alpha 的数据（样本内数据）进行比较，来衡量这种过度拟合的影响。样本内与样本外表现的比较不仅在单个 alpha 层面上有用，而且在给定设计者的所有 alpha 的汇总层面上，或者在给定设计者的 alpha 组群上也是有用的。这些对 alpha 组群的比较可以衡量设计者方法论的过度拟合倾向。

## 结论

本章讨论了 alpha 设计的主要要素，包括评估 alpha 的实用方法。还讨论了 alpha 开发完成后可能出现的一些潜在问题。通过利用计算能力和数据源的指数级增长，结合坚实的 alpha 设计框架，我们可以生成与市场共同演进的 alpha 和交易策略。
