# 第五章：如何开发 Alpha：案例研究

**作者：Pankaj Bakliwal 和 Hongzhi Chen**

*来源：Finding Alphas: A Quantitative Approach to Building Trading Strategies, Second Edition. Edited by Igor Tulchinsky et al., WorldQuant Virtual Research Center. © 2020 Tulchinsky et al., WorldQuant Virtual Research Center. Published 2020 by John Wiley & Sons, Ltd.*

---

本章将阐述如何设计 alpha、alpha 背后的逻辑、如何利用适当的信息将 alpha 想法转化为数学预测公式，以及如何改进这个想法。我们还将介绍一些评估 alpha 表现的重要概念。

在进一步讨论 alpha 开发和设计之前，让我们先研究一个简单的例子，以便更好地理解 alpha 是什么样的。

假设我们有 100 万美元的资金，希望持续投资于一个由两只股票组成的投资组合：Alphabet（GOOG）和 Apple（AAPL）。我们需要知道如何在这两只股票之间分配资金。如果我们对投资组合进行每日再平衡，就需要预测每只股票未来几天的收益。如何做到这一点呢？

影响股票价格的因素有很多，例如交易者行为、价格趋势、新闻、基本面公司变化，以及大型机构或公司内部人士——即持有某类公司注册股权证券 10% 以上的高管、董事或股东——的持仓变化。为了简化问题，我们可以将预测过程分解为两步：首先，使用新闻或价格趋势等单一因子预测每只工具的股票收益；其次，汇总所有不同的预测。

让我们尝试利用近期的价格趋势来开发一个 alpha，使用这两只股票的每日历史价格作为可用数据。下一步是提出一个合理的想法。假设根据历史价格，我们观察到这两只股票在过去一周内呈上升趋势。逻辑告诉我们，在没有任何额外信息的情况下，当股票价格上涨时，投资者倾向于获利了结并平掉多头头寸，这反过来会推动股票价格下跌。同时，当股票价格下跌时，投资者会看到以更低价格买入股票的机会，这反过来会推动股票价格上涨。

将想法转化为数学表达式并不总是简单的。但在上述情况下，可以简单地表示如下：

Alpha = −(1 周收益率)

负号表示当趋势向上时采取空头头寸，当趋势向下时采取多头头寸。特定金融工具中多空头寸的美元金额由公式给出的数值大小决定。这意味着价格趋势越强，价格回归的可能性越大。假设我们的算法分别为两只股票产生以下值：

Alpha(GOOG) = 2

Alpha(AAPL) = 1

上述值的比例为 2:1。这意味着我们持有的 GOOG 头寸应为 AAPL 的两倍；正数表示我们希望持有多头头寸，负数表示我们希望持有空头头寸。因此，以 100 万美元资金为例，我们希望在今日交易结束时做多 100 万美元的 GOOG 并做空 50 万美元的 AAPL。当然，这个例子假设交易成本为零。

因此，alpha 模型实际上是一个将输入数据（量价、新闻、基本面等）转化为向量的算法，该向量与我们希望在每个工具中持有的资金成正比。

Alpha(输入数据) → alpha 值向量

既然我们理解了什么是 alpha，接下来编写我们的第一个 alpha。[^1] 我们将在过程中介绍更多概念。首先，我们需要定义一个**投资范围**——即我们希望建立 alpha 模型的金融工具集合。让我们聚焦于美国股票市场。选择股票工具有不同的方法，例如使用标普 500 指数的成分股。假设我们使用美国流动性最强的 3,000 只股票作为研究范围（称为 TOP3000）。

接下来我们需要一个预测股票价格的想法。我们可以使用上面提到的均值回归思想，用数学表达式表示如下：

Alpha1 = −(close(today) − close(5 天前)) / close(5 天前)

要知道这个想法是否有效，我们需要一个模拟器进行回测。我们可以使用 WebSim 来实现这一目的。

回测期间为 2010 年至 2015 年，因此输出的每一行列出了该年度的年度表现。总模拟资金规模始终固定为 2,000 万美元；PnL 为年度盈亏。

年化收益率定义如下：

> Ann_return = ann_pnl / booksize / 2

年化收益率衡量 alpha 的盈利能力。

信息比率是我们关注的最重要的单一指标。其定义如下：

> Information_ratio = (average daily return / daily volatility) × √256

信息比率衡量 alpha 中所包含的信息量，大致反映 alpha 盈利的稳定性：越高越好。

最大回撤衡量从 PnL 局部最大值到后续局部最小值的最高峰谷损失，以资金规模除以二（即多头或空头一方）的百分比表示。

盈利天数占比衡量每年的正收益天数百分比。

日均换手率衡量投资组合再平衡的速度，定义如下：

> Daily_turnover = average dollars traded each day / booksize

每美元交易利润衡量每交易一美元所赚取的利润，定义如下：

> Profit_per_$_traded = pnl / total_traded_dollar

对于这个 alpha，总信息比率约为 1，年化收益率约为 31.2%，但最大回撤高达 39.22%。这意味着风险非常高，PnL 不太稳定。为了降低模拟中的最大回撤，我们需要消除一些潜在风险。可以通过使用一些风险中性化技术来实现这一点。行业风险和市场风险是股票市场最大的风险。我们可以通过要求投资组合在每个行业内实现多空平衡来部分消除这些风险。我们对 alpha 进行中性化处理，要求：

> 同一行业内 Alpha2 值之和 = 0

通过这样做，我们获得了新的样本结果，如图 5.2 所示。

如表 5.2 所示，信息比率提高到 1.37，年化收益率下降到 10.22%，但最大回撤显著降低到不到 9%。这是一个很大的改进。

我们 alpha 的数值大小是五天的收益率，作为预测因子不够精确；相对大小可能更准确。为了改进 alpha，我们引入截面排名（cross-sectional rank）的概念，即使用 alpha 值的相对排名作为新的 alpha 值。

> Alpha3 = rank(Alpha1)
>
> 同一行业内 Alpha3 值之和 = 0

## 结论

在本章中，我们阐述了 alpha 背后的逻辑，提供了一些想法的示例，并讨论了如何将这些想法转化为数学表达式并将其转化为工具头寸。我们还解释了如何分析和改进 alpha 的表现。图 5.5 中的流程图很好地概括了整个 alpha 逻辑。

你可以想出更多改进 alpha 的方法——发挥创造力就好。下一步是探索其他想法和数据集，寻找真正独特的东西。独特的想法是好的，因为你可以在其他人之前进行交易，从而可能获得更多利润。
