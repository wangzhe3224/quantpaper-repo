我们通常通过信息比率（IR）和信息系数（IC）等指标来衡量 alpha 预测的准确性和质量。IR 是超额收益与基准收益之比除以这些收益的波动性；其背后的思想是，在给定时间段内，具有高超额收益和低波动性的 alpha 能够持续预测未来收益。IC 衡量预测值与实际值之间的相关性，其中 1.0 表示完美的预测能力。

在评估 alpha 强度的背景下，高 IR 和高 IC 显然是理想的，但我们通常在不考虑现实约束的情况下衡量 alpha 的收益预测能力。我们假设流动性是无限的、交易是免费的，并且除了我们自己之外没有其他市场参与者。然而，由于实际交易策略必须遵守某些约束条件，一个经常做出正确预测的 alpha 如果也满足对市场条件的合理假设，将更容易被杠杆化。

## Alpha 预测期限

随着新信息的出现，预测会发生变化。无论是一只股票变动了一个最小价格单位、分析师修改了其推荐，还是公司发布了盈利报告，这种信息变化都可能成为交易活动的催化剂。我们通过换手率来衡量这种交易：交易总价值除以持有总价值。一家公司的股票价格变动远比其每股盈利变动频繁，因此，基于价格变动的 alpha（例如价格回归）通常比仅基于公司基本面的 alpha 具有更高的换手率。由于更多的交易机会提供更多捕获收益的机会，我们通常发现价格变动 alpha 的 IR 和 IC 往往高于基本面 alpha。

更具体地说，alpha 的换手率与其预测期限（horizon）相关——即价格变动被预测的未来时间长度。例如，一个期限为五天的 alpha 旨在预测从现在到五天后的价格变动。我们发现期限越长，不确定性越大；气象学家预测明天的天气比预测两个月后的天气要准确得多，我们能更好地预测下周在做什么，而不是明年这个时候在做什么。利用快速变化的信息并做出相应反应的能力通常会提高预测质量。类似地，在 alpha 研究中，我们预期具有较短预测期限的高换手率 alpha 比低换手率的长期 alpha 具有更好的预测能力。

然而，随着期限变短，执行时间也成为一种约束。使用五天期限 alpha 的交易者需要在今天建仓，并在五天后平仓，以充分捕获这一价格变动。相比之下，一个期限为三个月的 alpha 允许在交易之间有更长的捕获价格变动时间，从而在相同时间段内产生更少的交易和更低的换手率。对于极短期的 alpha（例如秒到分钟），甚至可能需要跨越买卖价差才能进入目标头寸，从而产生高昂的交易成本。由于其较长的执行时间，较长期限的 alpha 允许更好的执行优化，以及更高的资本容量。可以在利润被市场冲击成本所抵消之前向 alpha 投入更多资本。

## 交易成本

每笔交易都有成本。买入股票时，我们不仅要向经纪商支付佣金，还要支付价差成本。买方愿意支付的最高价格（买价）通常低于卖方愿意接受的最低价格（卖价）；这就是买卖价差（bid–ask spread）。要实现正收益，你必须以高于买入价的价格卖出所买的股票，或者在卖空的情况下，以低于卖出价的价格买回借入的股票。

我们预期这些成本与所讨论的范围或市场的流动性成正比。在流动性高的市场中，价差保持较窄，因为在任何时间点都有大量的买卖双方兴趣；当买方跨越价差推高买价时，卖方通常很快就会出现，利用有利的价格变动并将卖价拉回。另一方面，当流动性低或投资者兴趣集中在一侧时，价格更容易被推动，从而增加波动性并扩大价差。美国股票市场流动性最强的 500 只股票的平均价差约为 5 个基点（bps）。相比之下，较小的市场（如东南亚）的平均价差可能高达 25–30 个基点。^1^ 显然，这些市场的交易成本要高得多，因此了解 alpha 的期限和换手率特征是否适合该市场变得更加重要。可以说这些市场效率较低（即波动性较高），为收益留下了更大的机会，只要 alpha 的收益能够证明其交易成本的合理性，这当然是成立的。

当我们将交易成本计入 alpha 时，可能会发现较长期限 alpha 的整体交易成本比较短期限 alpha 更低。此外，较长期限 alpha 的较低交易成本也可能使其整体表现优于较短期限 alpha，尽管在考虑成本之前情况可能恰恰相反。一旦施加现实世界的约束，情况可能会看起来非常不同，因此在进行研究过程中保持对此的关注是有益的。

为了在 alpha 构建的背景下说明这种效应，考虑两个假设的 alpha，它们使用量价数据来预测第二天的价格。两个 alpha 在同一组工具上运作，我们假设两个 alpha 具有相同的收益和 IR。第一个基于近期波动率进行投资，第二个基于当前市场成交量进行投资：

1. α₁ = std(returns)
2. α₂ = log(volume)

我们看到第一个 alpha 投资于波动率更高的工具，但由于高波动率股票往往成交量较低且价差较大，策略很难分配大量资本，因为将那些收益转化为实际利润具有挑战性。第二个 alpha 投资于流动性较高的大盘股工具，在更现实的交易假设下可能表现更好。如果我们还假设成交量数据相对于波动率随时间更稳定，我们会预期第二个 alpha 的换手率更低，从而进一步提高其吸引力。

## 对冲效应

那么，在评估 alpha 时，我们是否只应看扣除成本后的表现？为什么要费心评估扣除成本前的 alpha 呢？直接对所有 alpha 收取交易成本，问题不就解决了吗？遗憾的是，事情没那么简单。通常，单个 alpha 太弱，不太可能作为独立策略表现良好；要构建一个潜在盈利的交易策略，组合经理通常需要组合多个 alpha。组合许多不同的 alpha 会产生更强、更充分的预测，更有可能克服交易成本和其他交易约束。多样化的 alpha 组合需要多样化的想法、方法和数据，从而产生具有广泛换手率特征的 alpha。换句话说：alpha 的换手率存在多样性。具有不同期限的 alpha 可能考虑不同类型的信息，这可能导致较低的相关性。

当 alpha 被组合在单一策略中时，alpha 的反向交易会"对冲"（cross）。考虑一个希望买入 200 股 IBM 的 alpha，与另一个持相反观点并建议卖出 300 股 IBM 的 alpha 组合。假设两个 alpha 的权重均为 1，合并后的 alpha 将卖出 100 股 IBM。200 股 IBM 的交易"对冲"了，不产生交易成本；这笔交易从未进入市场，因此是零成本的。只有合并后 alpha 将交易的 100 股才会产生成本。

如果一组 alpha 之间存在充分的对冲，合并后的 alpha 的换手率和整体交易成本可能低于单个 alpha 的换手率和交易成本。通过这种方式，我们仍然可以利用高换手率 alpha 来提高预测能力，同时将交易成本控制在可控范围内。虽然对单个 alpha 收取交易成本并观察其表现是一个可行的测试，但将其作为严格要求会过于限制。在理解单个 alpha 仍应控制换手率的前提下，如果由于这种对冲效应，它们对合并后 alpha 表现的贡献显著更好，那么它们的扣除成本后表现就不那么有意义了。

## 控制换手率

信息一直在变化，但（1）并非所有类型的信息都以相同速率变化，并且（2）并非所有信息都特别有用。为了说明起见，假设我们的 alpha 信号就是底层数据，没有特殊变换，即：

> α = data

数据就是预测，很显然数据频率驱动了 alpha 的换手率：数据变化越多，换手率越高。

在一个极端情况下，假设我们的数据是每只股票的每日价格。如果价格之前上涨我们就买入，如果之前下跌我们就卖出。价格几乎在每笔执行的交易中都会变化，因此我们可以预期我们的 alpha 会具有非常高的换手率。但我们理解市场中的大多数交易都是无关紧要的，我们可能会进行比我们希望的更多的交易。因此，我们的 alpha 平均来说很可能会亏钱。

季度公司公告每年只发生几次，仅基于此数据进行预测的 alpha 自然会有很少的交易机会和低换手率。但这类数据本质上是稀疏的。如果我们不注意这一点，绘制 alpha 的每日换手率可能会显示在这些季度事件周围出现交易活动的高峰。这表明 alpha 可能太快地建仓，也可能太快地平仓。我们理解这种 alpha 具有较长的期限，因此这种交易高峰可能是次优的。因此，即使是自然低换手率的 alpha，也可能通过平滑数据并将交易分散到更长的时间段来获得改进空间。关于处理和变换数据的各种方法，信号处理和类似领域已经有许多专著。对于我们的目的，一些简单的高级方法就足够了。

首先，确定数据中非常大的值是有意义的还是仅仅是异常值（即离群值）是有用的。如果测试表明它们确实是离群值，一种减少它们的方法是简单地钳制（clamp）数据，将大数据点降低到预定义的最小值和最大值，例如：

> clamp(data, min_value, max_value)

边界可以通过多种方式选择，例如数据分布的某个百分位数或某个标准差数。方法和相关参数将取决于数据的性质，可以通过回测来评估，同时注意只尝试少数合理的方法以避免过拟合。

另一方面，可能是数据中最小的变化导致了不必要的交易。这里的假设是这些小变动只是我们需要从数据中去除的噪声。假设测试表明数据中的小变化完全不必要，理想的行动是在变化不显著时不交易。一种简单的方法可能是要求变化超过一个阈值（或"hump"），否则保持之前的值：

> delta = data(t+1) − data(t)
>
> humped_delta = hump(delta, threshold)
>
> data(t+1) = data(t) + humped_delta

这里，如果 abs(delta) 小于阈值，则 humped delta 为 0。这最终去除了数据中小于给定阈值的所有变化，应该能显著降低我们 alpha 的换手率。然而，hump 方法导致更集中的交易特征；alpha 值会在一段时间内保持不变，直到阈值被跨越，此时会发生一次大的交易事件。如果这是期望的效果，这并没有什么问题。

在其他情况下，可以使用指数移动平均来平滑（衰减）交易，而不是完全停止：

> α(t) = λ × data(t) + (1 − λ) × α(t−1)

或者简单或加权移动平均：

> α(t) = β₀ × data(t) + β₁ × data(t−1) + … + βₙ × data(t−n)

这些方法可以提供类似的换手率降低，但具有更平滑的交易特征。以这种方式减慢信号时，决定使用哪种方法和参数将取决于数据和 alpha 的期限。通过仔细的实验和回测，我们可以选择一个最优点，使得离群值和噪声被减少，信号被平滑，换手率被降低，而表现被提高。然而，过度降低换手率（即超过 alpha 的期限）将导致表现下降，因为信号被减慢到超出捕获收益所需的程度。较快变化的信号比较长期限的信号能容忍的衰减更少，因此优化收益与换手率之间的权衡很重要。

## 示例

为了说明换手率对成本的影响，考虑众所周知的五天回归 alpha，它假设所有价格最终会回归到平均价格。这种 alpha 的一个简单实现是卖出过去五天价格上涨的股票，反之亦然：

> α = −1 × (close(t) − close(t−5))

对冲的频率也取决于 alpha 的换手率特征。换手率特征更稀疏的 alpha 平均来说比换手率更均匀的 alpha 具有更少的对冲机会。例如，五天回归 alpha 只要市场波动率保持恒定，通常每天交易量大致相同。而盈利动量 alpha 可能呈现周期性的换手率特征，在最常见的盈利公告时间周围出现活动高峰。考虑以下 alpha，它在盈利公告前 N 天对股票做多：

> α = 1 if 0 < days_until_earnings_announcement < N else 0

## 调优换手率

线性衰减等平滑方法实际上可能改善交易事件非常稀少的稀疏信号的表现。缩尾处理（winsorizing，即限制极端值）或对数据本身进行衰减也可能有助于在过度敏感于信息变化导致不必要头寸变化的情况下降低换手率。任何单一技术的效用最终取决于 alpha 本身。无论结果如何，理解 alpha 在各种换手率下的行为使我们能够了解其可交易性。一个在略微降低换手率后仍能保持大部分收益的 alpha 通常比在略微降低换手率后就失去所有收益的 alpha 更容易被杠杆化。

要理解 alpha 想法的稳健性和可交易性，在各种工具范围上对其进行测试并了解每个市场的流动性是很重要的。给定的换手率水平在流动性最强的范围中可能是可接受的，但在扩展到包含流动性较差的工具时可能变得不可交易；在一个国家有效的水平在欠发达市场可能不适用。例如，一个以 X% 换手率交易美国流动性最强的 500 只股票的 alpha 可能完全可以接受，但对于一个在更大范围（流动性较差的工具，例如美国流动性最强的 3,000 只股票）上运行的类似 alpha，或一个在发展中市场交易的 alpha，在考虑交易成本的情况下，在较低换手率下评估表现是明智的。

一个好的换手率水平是最大化利润或 IR 与换手率之比的水平。更重要的是，在不同流动性集合和各种换手率水平下测试和分析 alpha 表现的练习，可以为该 alpha 的稳健性和可交易性提供洞察和信心。归根结底，一切都是相对的。
