Alpha 通过许多不同的指标进行评估，例如信息比率、收益率、最大回撤、换手率和利润率。这些指标主要来自 alpha 的损益（PnL）。例如，信息比率就是平均收益除以收益的标准差。Alpha 的另一个关键品质是其独特性，通过给定 alpha 与其他现有 alpha 之间的相关系数来评估。相关系数较低的 alpha 通常被认为对现有 alpha 组合增加更多价值。

如果组合中的 alpha 数量较少，相关性的重要性就较低。然而，随着 alpha 数量的增加，测量它们之间相关系数的不同技术变得更加重要，有助于投资者分散投资组合。组合经理希望在其投资组合中包含相对不相关的 alpha，因为分散化的投资组合有助于降低风险。一个好的相关性度量需要识别一个 alpha 相对于组合中其他 alpha 的独特性（值越小表示独特性越好）。此外，一个好的相关性度量还需要能够预测两个 alpha PnL 向量（时间序列向量）的运动趋势。Alpha 之间的相关性可以基于 alpha PnL 相关性或 alpha 值相关性来计算。

## Alpha PnL 相关性

给定两个 alpha PnL 向量（我们用粗体字母表示向量）：

**P**ᵢ = [ Pᵢ₁, Pᵢ₂, …, Pᵢₙ ] ∈ ℝⁿ

**P**ⱼ = [ Pⱼ₁, Pⱼ₂, …, Pⱼₙ ] ∈ ℝⁿ                                       (1)

其中 Pᵢₜ 和 Pⱼₜ 分别表示第 *i* 个和第 *j* 个 alpha 在第 *t* 天的 PnL，*n* 是用于测量相关性的天数，上标 *T* 表示矩阵转置。注意：测试通常选择相关性天数为两年或四年而非全部历史，以节省计算资源。

### Pearson 相关系数

Pearson 相关系数，也称为 Pearson 乘积矩相关系数，是无量纲的，取值范围为 −1 到 1。该数学公式由 Karl Pearson 于 1895 年首次提出：

> r = cov(**P**ᵢ, **P**ⱼ) / (σ_Pᵢ · σ_Pⱼ)                              (2)

其中 cov(**P**ᵢ, **P**ⱼ) = E[**P**ᵢ · **P**ⱼ] − E[**P**ᵢ] · E[**P**ⱼ] 是协方差，σ_Pᵢ 和 σ_Pⱼ 分别是 **P**ᵢ 和 **P**ⱼ 的标准差。对于两个 PnL 向量，系数使用样本协方差和方差来计算。具体地：

> r = Σₜ₌₁ⁿ (Pᵢₜ − P̄ᵢ)(Pⱼₜ − P̄ⱼ) / √[Σₜ₌₁ⁿ (Pᵢₜ − P̄ᵢ)² · Σₜ₌₁ⁿ (Pⱼₜ − P̄ⱼ)²]   (3)

该系数对任一变量的线性变换保持不变。如果相关系数为正，意味着两个 alpha 的 PnL 趋于同方向运动。当 Pᵢ 的收益为正（负）时，Pⱼ 的收益也有趋向为正（负）的可能。相反，负相关系数表示两个 alpha 的 PnL 趋于反方向运动。零相关意味着两个 PnL 向量之间没有关系。图 8.1 显示了使用两年数据的最大相关性随交易信号数量的变化。

Alpha 旨在预测各种金融工具未来的走势。因此，分析需要扩展到时间序列，其中包括带有时间索引的随机变量序列。在 alpha PnL 向量的情况下，观测值是 alpha 在一天中的盈利（+）或亏损（−）。下面我们简要回顾点积，然后讨论基于时间的相关性。

### 基于时间的相关性

点积（内积）定义为两个数字序列对应元素乘积之和：

> **P**ᵢ · **P**ⱼ = |**P**ᵢ| · |**P**ⱼ| · cos(θ)                         (4)

其中 |**P**| 是 PnL 向量的模或大小，θ 是两个向量之间的夹角。点积的一个重要应用是找到两个向量之间的夹角，因为夹角可以通过以下方式求出：

> cos(θ) = **P**ᵢ · **P**ⱼ / (|**P**ᵢ| · |**P**ⱼ|) = Σₜ₌₁ⁿ Pᵢₜ · Pⱼₜ / √[Σₜ₌₁ⁿ Pᵢₜ² · Σₜ₌₁ⁿ Pⱼₜ²]   (5)

当夹角为零时，两个 PnL 向量落在同一条线上，cos(θ) = 1。当夹角为 π/2 时，向量正交，cos(θ) = 0。

基于时间的相关性将每个 alpha 的 PnL 向量视为时间序列序列，并为每天分配权重。两个 PnL 向量之间的相关性因此定义为：

> r = Σₜ₌₁ⁿ wₜ · Pᵢₜ · Pⱼₜ / √[Σₜ₌₁ⁿ wₜ · Pᵢₜ² · Σₜ₌₁ⁿ wₜ · Pⱼₜ²]      (6)

自然地，较大的权重分配给最近的 PnL 值（wₜ ≥ wₜ₊₁，t = 1, 2, …, n）。例如，wₜ = 1/n，与时间索引 t 成反比。该公式将输入向量对（**P**ᵢ, **P**ⱼ）转换为时间缩放向量，然后计算两个缩放向量之间的夹角：

**P**'ᵢ = [ w₁Pᵢ₁, w₂Pᵢ₂, …, wₙPᵢₙ ] ∈ ℝⁿ

**P**'ⱼ = [ w₁Pⱼ₁, w₂Pⱼ₂, …, wₙPⱼₙ ] ∈ ℝⁿ.                       (7)

因此，基于时间的相关性仍然保留了传统点积的许多理想特性，如交换律、分配律和双线性性质。

Pearson 相关系数可以在此处对公式 7 中的两个缩放向量进行计算。我们可以看到，中心化变量在 Pearson 相关系数的意义上具有零相关性或不相关（即从向量的每个元素中减去该向量的均值），而正交性是原始变量的属性。零相关性意味着两个去均值向量正交。去均值过程通常会改变每个向量的角度以及两个向量之间的角度。因此，两个向量可能不相关但非正交，反之亦然。关于线性无关、正交和不相关变量的更多信息，参见 Joseph Rodgers 等人（1984）。

### 广义相关性

数据变换是进行适当数据分析的重要工具。变换有两种：线性和非线性。线性变换（如乘以或加上一个常数）保持变量之间的线性关系，因此不会改变变量之间的相关性。下面我们将考虑非线性变换，它们通常会修改两个变量之间的相关性。

上述两个相关性公式使用每日 PnL 值计算相关系数。广义相关性创建一个矩阵 **M**ₖₓₙ，然后将两个 PnL 向量转换到不同的欧几里得空间：

**Q**ᵢ = **M**ₖₓₙ · **P**ᵢ ∈ ℝᵏ

**Q**ⱼ = **M**ₖₓₙ · **P**ⱼ ∈ ℝᵏ.                                      (8)

常规相关性现在在变换域中计算，变换矩阵 **M**ₖₓₙ 增加了一些额外特征。如果 **M**ₖₓₙ = **I**（单位矩阵），我们得到常规相关性方案。这里我们来看一些其他特别有用的变换。

每周 PnL 相关性针对每周而非每日的 PnL 向量计算。在这种情况下，*k* = *n*/5，变换矩阵变为：

> **M**ₖₓₙ = (mᵢ,ⱼ)，其中 mᵢ,ᵢ = 1 × 5，*t* = 1, 5，其余元素为零。     (9)

每周相关性通常高于每日值，但这是理解 alpha 的另一种方式。每月 PnL 相关性使用类似的方法计算。

基于时间的相关性是广义相关性的另一种形式，对应于方阵对角变换矩阵：

> **M**ₖₓₙ = (mᵢ,ⱼ)，其中 mᵢ,ⱼ = wᵢ 如果 i = j，mᵢ,ⱼ = 0 否则。   (10)

在此变换下，输入 PnL 向量被转换为时间缩放向量，如公式 7 所示。

符号 PnL 相关性是 PnL 向量相关性的另一种形式，其中相关性基于 PnL 值的符号而非值本身来计算。变换矩阵现在是一个依赖于数据的对角矩阵，其元素值取决于输入 PnL 向量。因此，输入对（**P**ᵢ, **P**ⱼ）被转换为以下形式：

**Q**'ᵢ = [ sgn(Pᵢ₁), sgn(Pᵢ₂), …, sgn(Pᵢₙ) ] ∈ ℝⁿ

**Q**'ⱼ = [ sgn(Pⱼ₁), sgn(Pⱼ₂), …, sgn(Pⱼₙ) ] ∈ ℝⁿ                (11)

其中 sgn(*x*) 是符号（符号函数），取值为 {−1, 0, 1}，对应于 *x* 的（负、零、正）值。

## Alpha 值相关性

用 **α**ᵢ(*t*) 表示第 *t* 天的 alpha 头寸向量：

> **α**ᵢ(*t*) = [ αᵢ₁(*t*), αᵢ₂(*t*), …, αᵢₘ(*t*) ] ∈ ℝᵐ          (12)

其中 *m* 是工具数量，αᵢₖ(*t*) 是（或正比于）投资于第 *k* 个工具的金额，Σₖ₌₁ᵐ αᵢₖ(*t*) 是（或正比于）投资组合中的总金额。有时除了 PnL 向量之外，考虑 alpha 头寸向量也是有用的。特别是，组合经理通常考虑两种基于头寸的相关性度量：头寸相关性和交易相关性。

两个 alpha 在 *d* 天期间的头寸相关性通过形成以下两个向量来计算：

> **α**ᵢ = [ **α**ᵢ(1), **α**ᵢ(2), …, **α**ᵢ(*d*) ] ∈ ℝ⁽ᵐˣᵈ⁾       (13)

> **α**ⱼ = [ **α**ⱼ(1), **α**ⱼ(2), …, **α**ⱼ(*d*) ] ∈ ℝ⁽ᵐˣᵈ⁾.

两个 alpha 在 *d* 天期间的交易相关性通过形成两个差分向量来计算：

> Δ**α**ᵢ = [ **α**ᵢ(1) − **α**ᵢ(2), **α**ᵢ(2) − **α**ᵢ(3), …, **α**ᵢ(*d*) − **α**ᵢ(*d*+1) ] ∈ ℝ⁽ᵐˣᵈ⁾    (14)

> Δ**α**ⱼ = [ **α**ⱼ(1) − **α**ⱼ(2), **α**ⱼ(2) − **α**ⱼ(3), …, **α**ⱼ(*d*) − **α**ⱼ(*d*+1) ] ∈ ℝ⁽ᵐˣᵈ⁾.

通常，取 *d* = 20 天就足够了，因此 alpha 向量的维度为 20 乘以范围中工具的数量。如果两个 alpha 在不同工具范围上持有头寸，则使用两个范围的交集进行计算。

## Alpha 组合相关性

上述相关性方法用于检查两个单独 alpha 之间的相关性。自然地，给定一个 alpha 组合，最大相关性已被用作衡量给定 alpha 增加价值的指标。随着 alpha 数量的增加，平均相关性比单一最大相关性变得更加重要。

T-corr 定义为给定 alpha 与所有其他 alpha 的相关性之和。平均相关性和 T-corr 与最大相关性一起，提供了衡量 alpha 价值增加的额外有力指标。

## 结论

我们综述了评估 alpha 之间以及 alpha 组合之间 PnL 和头寸相关性的几种不同方法。当然，还有更多统计性而非代数性的方法来评估相关性，如 Spearman 秩相关和 Kendall 秩相关。在本章的范围内，我们只涵盖了评估 alpha 相关性的一些最常用方法。由于计算资源的限制，PnL 相关性可以在较长的时间段（2–4 年或更长）内进行评估，相比之下，alpha 值相关性需要较短、近期的时间段。

一个合理的想法通常可以用来开发许多 alpha，取决于不同的技术和数据集。由于它们基于单一想法开发，这些 alpha 倾向于高度相关。有时将一些或所有这些高相关性的 alpha 组合起来是有益的，而不是只选择一个 alpha 并删除所有其他的。两个 alpha 可能在历史上具有高度相关的表现，但未来是不确定的，并不总是清楚哪个可能在未来增加更多价值。因此，对于两个高相关性的 alpha（例如 A 和 B）的资源分配，可以将资源（不一定相等）在 A 和 B 之间分配，而不是将所有资源分配给单一 alpha。单一 alpha 不能完全描述一个想法的每个方面，但每个 alpha 以不同的方式代表该想法；因此，同时使用所有这些 alpha 可能提供该想法更完整的视角，使整体策略更加稳健。

Alpha 相关性的最终目标是找到给定现有 alpha 组合时添加一个新 alpha 的真实价值，随着 alpha 数量的增长，这一点变得越来越重要。使用多种相关性方法有助于更好地理解近期历史以及更长时间段内的 alpha 信号。基于全新交易想法的 alpha 通常是独特的，并且为 alpha 组合增加最多价值。
