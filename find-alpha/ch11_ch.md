# 第十一章：三轴计划

**作者：Nitish Maini**

*来源：Finding Alphas: A Quantitative Approach to Building Trading Strategies, Second Edition. Edited by Igor Tulchinsky et al., WorldQuant Virtual Research Center. © 2020 Tulchinsky et al., WorldQuant Virtual Research Center. Published 2020 by John Wiley & Sons, Ltd.*

---

量化投资的世界正在极其快速地增长。量化交易者正在利用数学、计算机编程以及不断增长的各类数据集，开发预测市场波动的新方法。然而，发现新的 alpha 可能是一个巨大的挑战，特别是对于新的量化交易者来说。要高效探索可能的 alpha 的广阔宇宙——我们称之为 alpha 空间——需要一个结构化的策略、一个锚定点和一个定向技术，即三轴计划（Triple-Axis Plan，TAP）。

TAP 可以通过为 alpha 搜索的概念化提供框架来帮助新的量化交易者定义 alpha 空间。它还可以帮助更有经验的量化交易者——他们能够定义构成每个轴的实体，然后分析其投资组合中现有的 alpha——更高效地定位他们的工作。

新的量化交易者很容易被开发 alpha 的挑战所压倒。他们会问自己："我如何找到 alpha？我如何开始搜索？"即使是有经验的量化交易者在处理许多 alpha 时，也可能遗漏构建稳健、分散化投资组合所需的关键组件。例如，alpha 投资组合构建中最困难的方面之一是需要优化投资组合的分散化水平。在自动化交易系统中，分散化决策是人类干预的主要领域。要可视化包含数百或数千个 alpha 的投资组合的许多组成部分及其相互作用并不容易。

TAP 正是出于这些关注而产生的。当新的量化交易者开始进行 alpha 研究时，许多人首先在互联网上搜索关于开发 alpha 的文章。这些文章大多聚焦于回归和动量，因此初学者可能最初会花大量时间构建回归或动量 alpha。但随着新量化交易者变得更加熟练，他们开始怀疑在向投资组合添加新 alpha 时是否真的在创造价值。虽然他们认为自己在分散化投资组合，但他们可能只是反复开发相同类型的 alpha。尽管它们可能看起来具有低相关性，但相同 alpha 类型的变体往往具有相同的失败模式，无法提供真正分散化投资组合的全部好处。

几乎每个人在开始研究 alpha 时都会陷入这个陷阱。每个成功的量化交易者都有一座金矿；他在自己的矿里越挖越深，尽可能多地提取。一个人开发了一个非常强的动量站点；另一个人有一个非常强的基础面站点；第三个人建立了一个非常强的回归站点。然而，他们经常忘记外面还有多个金矿。在一个区域开采完毕后，他们需要继续寻找和探索其他矿。

TAP 本质上只是一个组织复杂多维 alpha 空间的工具。它在投资组合分散化方面提供了许多优势。alpha 空间是广阔的，具有高且不断增长的自由度，可能的 alpha 数量几乎是无限的，每个区域或 alpha 簇都具有需要发现和探索的不同地形。量化交易者有大量选择。她可以预测从微秒到年不等的时间间隔的交易。她可以对不同资产类别进行预测，最常见的是股票、债券、大宗商品和货币。但量化交易者可以操纵的可能元素集合一直在增长——更多的数据集、更多的参数、更多的想法。随着可用数据以如此快的速度扩展——事实上，因为有如此多的数据——开发一个合理的成功概率的计划来组织这个复杂的格局变得很重要。每个成功的量化交易者都需要一个策略来在噪声世界中识别可行的信号，定位可能范围中的特定区域，并选择最适合该目的的数据类型和特定金融工具。你需要一个模型来结构化你的搜索。TAP 就是这样一个模型。

TAP 背后的动机是需要将单个 alpha 推广到尽可能广泛的类似 alpha 家族。三个特别有用的类别或泛化轴是：想法与数据集（Ideas & Datasets）、表现参数（Performance Parameters）以及区域与范围（Regions & Universes）。

## TAP

在这个复杂格局中搜索 alpha 的过程可能因 alpha 背后的想法和期望的目标函数而有很大差异，目标函数可能包括信号的属性，如换手率、交易频率或可交易工具的范围。为了更容易地可视化，TAP 将资产类别内的 alpha 结构化为三维空间（见图 11.1）。

用于开发 alpha 的想法范围可以从传统指标（如回归、动量或配对交易）到较少见的指标（如机器学习、领先-滞后或季节性）。随着计算能力的增强，可用于实现这些想法的数据集数量增长如此之多，以至于我们可以用使用的不同数据集数量来衡量信号池的多样性。最广泛使用的数据集包括量价数据、公司基本面、分析师推荐、股票情绪、社交媒体和期权，但还有许多其他数据集。

这些想法可以在不同地区的不同金融工具组上生成和实现。个别证券交易所的市值和特定地区或国家的监管环境通常决定了量化交易者的地区选择。美国和欧洲传统上交易量最大，尽管亚洲市场近年来吸引了越来越多的关注。交易工具可以根据其流动性、行业或板块等分类特征或其他标准来定义，具体取决于 alpha 想法。

为了在不同市场条件下寻求成功，量化交易者可以通过开发尝试实现一个或多个目标函数（通常与解释其表现的属性相关）的 alpha 来构建分散化、稳健的投资组合。量化交易者旨在通过最大化 Sharpe 比率和收益率或最小化回撤和交易成本来产生利润。TAP 方法是在这个世界中定向自己的方式之一，每个轴提供了一个不同的镜头来聚焦你的研究。根据方法的不同，可以向每个轴添加许多元素。表 11.1 提供了三个轴的简化示意图。当然，每个轴中可能的组成条目可以更加广泛。

**表 11.1：TAP 涵盖的一些想法、数据集、区域、范围和表现参数**

| 三个轴 | |
|---|---|
| **想法与数据集** | |
| 想法 | 回归、动量、季节性、学习、领先-滞后 |
| 数据集 | 基本面、分析师、情绪、社交媒体、期权 |
| **区域与范围** | |
| 区域 | 美国、欧洲、亚洲（日本或除日本外）、美洲、全球 |
| 范围 | 可以使用流动性配置来定义，如 TOP50、TOP100、TOP200、TOP1500；任何特定行业或板块；任何选定的工具或工具组 |
| **表现参数** | 高收益、高 Sharpe 比率、低成本、低回撤 |

## 实施 TAP

TAP 采用一个相对简单、机械化的过程，既反映又组织了 alpha 空间复杂的金融现实。它允许策略制定者在三个轴上填补空白，从而揭示投资组合中可能缺失的组件。

TAP 在三个层面上运作。第一个层面涉及确定一个初始聚焦区域。用户可以从单一轴上相对通用的聚焦开始——比如以动量作为一个想法；或以特定区域为目标，如美国或欧洲；或以表现参数为目标，如高 Sharpe 比率或最小回撤。第二个层面涉及通过系统地填充其他轴的元素来细化聚焦。TAP 允许量化交易者在一个轴上选择目标，同时保持操纵其他两个轴的灵活性。独立地在每个目标上工作有助于量化交易者发展技能并积累在该领域构建 alpha 所需的知识。第三个层面涉及执行：用代码实现算法，测试初始想法，然后回到三个轴上细化基本概念。

考虑这个相对简单的例子。假设一个量化交易者正在探索可能在主要由流动性股票组成的范围中有效的想法。他选择首先聚焦于区域与范围轴，并选择流动性范围——美国的前 500 或 300 家公司。后来，为了在地理上实现分散化，他需要亚洲和欧洲以及美国的 alpha 和策略。这应该相对容易，因为在已经开发了动量和回归 alpha 并熟悉流动性范围的属性之后，将这种知识应用于欧洲和亚洲是很自然的。与此同时，研究人员意识到仅关注降低 alpha 的成本或提高其 Sharpe 比率是不够的；产生高收益也很重要。然而，获得更高收益通常需要与其他参数的效果进行权衡。因此，寻求更高收益需要更高水平的技能。现在量化交易者可以再次迭代他之前的工作，继续致力于开发高收益动量 alpha、高收益回归 alpha 和高收益流动性 alpha。

要达到期望的水平，分散化需要系统地掌握 TAP 三个轴的使用：

- 选择聚焦于动量 alpha 会冻结想法与数据集轴。在这种情况下，接下来的步骤是在其他两个轴上进行分散化，通过选择不同的区域与金融工具范围来开发动量 alpha，以及定位 alpha 以优化不同类型的表现参数。
- 类似地，选择在美国金融板块上开发 alpha 固定了区域与范围轴，但保留了使用不同想法或数据集来优化不同表现参数的灵活性。
- 选择开发高收益 alpha 固定了你的表现参数轴，保留了在任何类型的数据集、想法、区域和范围上变化其他两个轴以寻求期望收益目标的灵活性。

金融市场的复杂性允许广泛的粒度和精度，这正是 alpha 空间的丰富性和寻找新 alpha 挑战的令人兴奋之处。重要的是要认识到没有单一万无一失的解决方案。金融世界是由个人对资产、收益和风险的估值之间的特异性差异所塑造的。因此，潜在价值在于尽可能广泛地探索已知领域，即使在那些通常被当作噪声而忽视的领域；它们可能最终成为无限的知识来源。量化交易者只需要对从哪里开始搜索以及如何组织这项工作做出深思熟虑的选择。

## 结论

TAP 是一个可视化影响 alpha 表现的各个维度的工具。因此，它可以为量化交易者提供对复杂 alpha 空间更大的清晰度和洞察力。TAP 不是确保成功的秘密武器，但它确实帮助经验不足的量化交易者开始搜索并理解潜在问题，它也帮助更有经验的策略制定者增强非常复杂的 alpha 投资组合的分散化。为了最有效，TAP 应该整合到 alpha 开发、细化、测试和执行的所有必要步骤中。
