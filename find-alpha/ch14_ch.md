# 第十四章：风险与回撤

**By Hammad Khan and Rebecca Lehman**

## 引言

寻找 Alpha 的核心在于以风险换取收益。每个人都了解什么是收益，但什么是风险？研究人员常常将不同类型的风险混为一谈，而这些风险需要不同的度量方法和控制手段。事实上，潜在风险类型的集合是无限的。在风险谱系的最远端是 Knight 不确定性和黑天鹅事件——这些风险在事前是不可知的，但事后可以被合理化并过度拟合。关于这些风险，唯一有建设性的说法是它们确实存在，而在事件发生后试图对其进行合理化只会徒劳无功。过于复杂的风险模型可能包含层层叠加的"本轮"，旨在缓解上一次黑天鹅事件的影响，但对下一次事件却毫无作用，只会使模型变得更加脆弱。稍近一些的是资产特有风险和操作风险，从业者可以也应该考虑这些风险，但它们不适合进行一般性的讨论。本章将聚焦于风险谱系的近端——最明确且最常被考虑的风险类型，它们可以大致分为外在风险和内在风险。

许多 Alpha 暴露于与其收益来源无关的外在（或称外部）因素中，例如特定行业或整个市场的行为。其他风险因素包括那些已被大量套利消弭但交易仍然高度活跃、容易出现动量期和清算潮的 Alpha 策略，例如 Fama–French 因子和 Barra 因子。这些因子构成了 Alpha 的外在风险，可以在不破坏业绩的情况下进行部分或完全对冲。一种特殊的外部危险是事件风险，即 Alpha 的常规业绩驱动因素暂时被某个外部因素所压倒，例如突发新闻公告，这些事件可能被预期，也可能未被预期。但即使对所有已知的外部因素进行了中性化处理，Alpha 仍然包含其自身的内在风险，在套利有限的前提下，正是这种内在风险最终驱动着收益。虽然内在风险无法被消除，但它可以被也应该被估计和控制。不同的内在风险度量——如波动率、风险价值（value at risk）和预期尾部损失——可用于为每个 Alpha 选择适当的杠杆水平或资本配置。有一种内在风险特别难以估计，那就是回撤风险。对于许多投资者来说，回撤是关键因素——甚至可能比历史波动率更重要——因为过大的回撤对其公司的持续经营构成威胁。回撤在经验上特别难以估计，因为它们是非线性的，并且比波动率和风险价值等其他风险度量更容易在样本内被过度拟合。然而，由于其实际重要性，值得讨论一些预测和控制回撤的技术。

## 风险估计

### 基于持仓的度量

对 Alpha 最简单、或许也是最稳健的风险估计是基于其当前持仓的。这些度量计算简便，不依赖于关于 Alpha 未来行为的任何假设，但它们往往较为脆弱，且只能度量极端风险。与集中于特定证券、一组相关证券或因子分位数相关的外在风险可以通过持仓集中度来度量。过度集中本身就是一种风险，因为如果 Alpha 对高度集中持仓的收益预测出错，就可能遭受严重损失。

给定一个 Alpha 向量形式的因子风险，可以通过 Alpha 在该向量上的正交投影来估计。如果预期某个新闻事件会影响一组特定的工具，事件风险可以度量对这些工具的敞口。另一种基于持仓的因子风险方法是，将给定持仓的历史收益与因子的历史收益进行回归。Beta 系数，即因子载荷，定义了与这些持仓相关的风险。

给定一组持仓的内在风险价值（intrinsic value at risk）就是该组持仓收益分布中第 *p* 百分位的损失（通常 *p* = 5% 或 10%），而预期尾部损失则是低于第 *p* 百分位条件下的平均损失。可以分别计算每个单独持仓的风险价值（不假设持仓之间的相关性）和整个投资组合的风险价值（隐含假设工具的相关性结构是稳定的）。

### 基于历史损益的度量

通常可以通过观察 Alpha 历史持仓的业绩（而非仅看当前持仓）来获得更平滑的风险估计。这假设了 Alpha 的持仓已适应当前环境。由于历史损益序列随时间变化较慢，这些度量更加平滑，可以在不引起过度换手的情况下更容易地进行控制，但它们在检测 Alpha 风险特征或环境变化时可能较慢。检测外在风险的一种方法是考虑特定行业的损益集中度。即使持仓看起来并不集中，如果损益高度集中在某些行业，那么其他行业就没有为 Alpha 的分散化做出贡献。参见图 14.1 的示例。

类似地，研究人员应该检查 Alpha 业绩相对于极端 Alpha 值的分布。测试这一点的一种简单方法是将 Alpha 值分为五分位数，并找出来自每个五分位数的平均收益（和标准差）。在一个理想的 Alpha 中（图 14.3），最高的五分位数（如果 Alpha 以 0 为中心，则是高度正的 Alpha 值）产生高度正的未来收益，最低的五分位数（高度负的 Alpha 值）产生高度负的未来收益。

由于此类 Alpha 仅在尾部情况下具有良好的预测能力，因此如果尾部信息在未来退化，实际业绩的广度将下降，回撤的概率将增加。由于此类 Alpha 的中间五分位数不包含任何信息，因此将绝对值低于某个噪声阈值的工具剔除是合理的。然而，由于这样做的结果是 Alpha 交易的工具数量更少，我们可以预期它在发生单一工具冲击时的波动率更高、稳健性更低。

基于损益的因子风险可以通过检查因子分位数上的收益分布来估计，或者通过将 Alpha 的实际历史收益与所选风险因子的历史收益进行回归来估计。Alpha 的内在风险也可以度量实际历史损益序列（而非当前持仓）的年化波动率、风险价值或最大回撤。

在度量外在和内在风险时，考虑时间尺度很重要。较窄的窗口或更快的衰减因子使风险度量对体制转换更加敏感，但代价是历史记忆减少。在选择这些参数时，考虑 Alpha 的时间结构也很重要。如果 Alpha 快速调整其持仓，它更有可能快速改变其风险敞口，因此较窄的时间窗口是合理的。如果 Alpha 具有自然的周期性（例如，农产品 Alpha 的季节性），在该周期的分数倍上进行风险度量往往会产生噪声，因此所有窗口应该是该周期的整数倍。通常值得将较短和较长时间范围的估计结合起来，以增加稳健性，并作为 Alpha 基本时间结构可能失效时的保障。

## 回撤

回撤是 Alpha 从其前期高点的百分比损失。例如，如果 Alpha 自成立以来实现了 20% 的收益，然后在接下来的几天（或几周）内下跌至 18% 的收益，回撤度量为 2%。由于没有 Alpha 每天都赚钱，每个 Alpha 都有回撤。

投资者通常需要关注回撤的两个特征：

- Alpha 在整个历史期间（以及在每个历史年份中）经历的最大回撤。
- 最长回撤的持续时间。

过度剧烈或过长的回撤可能导致个人投资者破产，或引发资金从基金撤出，因此控制回撤非常重要。

在研究回测结果时，Alpha 的回撤应该与其其他特征——例如年化收益和信息比率——一起衡量。年收益应该超过回撤。有时一个原本稳健的 Alpha 会出现突然的急剧回撤，然后恢复到之前一致的表现。在其他情况下，回撤由许多天缓慢而稳定的负面表现组成，然后 Alpha 才开始再次表现良好。当然，当实际 Alpha 部署或样本外测试中的业绩转为负面时，无法实时知道 Alpha 是已经完全失效，还是只是碰到了应该很快恢复的暂时性回撤。因此，衡量样本内期间历史回撤的深度和持续时间很重要。这为我们提供了一个基准，可以据此衡量样本外和实盘交易中的表现。

遗憾的是，由于回撤是罕见的，它们也很容易被过度拟合。很容易"打上一仗"——想出一个巧妙的主意来防止回测中看到的大回撤，但对防止实盘交易中的下一次回撤毫无帮助。衡量回撤风险的一种有用方法是自助法（bootstrapping）。其步骤如下：

1. 度量 Alpha 损益的自相关系数。当只有有限个显著的自相关系数时，使用自助法才有意义。
2. 通过随机选择长度等于自相关周期的损益片段（有放回），创建 1,000 个合成的 10 年损益序列。
3. 绘制合成损益序列最大回撤的分布。第 90 百分位即为自助法回撤。

自助法之所以有用，是因为虽然很容易针对导致回撤的特定市场条件编造一个看似合理的故事，并简单地过度拟合以在这些条件下降低风险，但要过度拟合整个收益分布和自相关结构则困难得多。如果已实现的回撤减少了但自助法回撤没有减少，那么风险并没有被控制，只是被掩盖了。如果自助法回撤得到了控制，则更安全地认为底层分布不会产生极端回撤。

## 控制风险

### 尽可能分散化

由于不同工具暴露于不同类型的风险，且波动率与独立变量数量的平方根成正比，因此只要持仓集中度可控，Alpha 或投资组合的外在和内在风险通常可以通过分散化来降低。例如，仅基于 FTSE 100 构建的 Alpha 比基于全部英国和欧洲股票构建的 Alpha 的分散化程度更低。分散化可以包括新工具、新地区或行业以及新资产类别。工具之间的相关性越低，风险就越接近理想的中心极限定理。然而，分散化也有其限度。如果工具过于多样化，波动率可能过于异质，无法使所有工具在不产生过度集中风险的情况下做出有意义的贡献；或者工具的行为可能差异过大，使得相同的 Alpha 思路不再适用。此外，随着底层工具池的扩大，其他风险可能随之出现，如国家和货币敞口、政治风险和交易对手风险。这些风险应予以考虑和缓解。

### 降低外在风险

外在风险可以通过中性化或对冲来控制。硬中性化（hard neutralization）是将给定风险强制归零。在持仓集中的情况下，可以通过从各持仓中减去组均值、将持仓向量与因子向量正交化、或减去 beta 乘以因子来轻松实现（假设做空没有限制）。美元中性或行业中性持仓通过硬中性化实现。软中性化（soft neutralization）是对给定风险的敞口设置上限，可以通过减去一部分敞口或使用约束优化方法来产生持仓。

对冲是使用一个工具或一组工具作为对冲，以抵消其他工具或工具组所承担的风险。例如，可以通过标普 500 期货或交易所交易基金（ETF）对冲股票投资组合的市场 beta，或通过货币即期或期货对冲全球债券投资组合的货币风险。由此产生的风险控制并不完美，因为对冲工具与底层风险的相关性不完全，但在中性化不切实际的情况下——例如做空不可能或成本过高，或者风险是短期事件风险且对冲工具比底层投资组合更具流动性——这种方法通常是有用的。

### 降低内在风险

内在风险以及软中性化或对冲后剩余的外在风险，应通过动态仓位管理来控制。大多数 Alpha 都受益于对波动率、风险价值、预期尾部损失和持仓集中度的广泛上限。当风险上升时，投资组合规模应相应缩减，以免 Alpha 仅在少数高风险交易日就冒失去其长期损益的风险。具有广泛 beta 或 risk-on/risk-off 行为的 Alpha 还可以使用其他相关代理指标——如 CBOE 波动率指数（VIX）、流入 risk-on/risk-off 资产的资金流，或相关性特征值的飙升——作为信号来调整其风险偏好以适应当前市场条件。没有任何单一风险度量能完全捕捉风险特征的复杂性，因此将多个相关度量结合起来并使用最保守的一个是有用的。对于容易受到某些可提前预知的事件风险（例如央行会议和数据发布）高度影响的 Alpha，应提前缩减或退出其持仓，如果无法及时缩减，则应使用更具流动性的工具进行对冲。止损和止盈阈值也可以被视为极短期仓位管理约束的例子，在交易达到预期风险水平后削减持仓并防止过度回撤。

### 直接退出

并非所有风险都能被度量或控制。如果 Alpha 的基本假设似乎面临崩溃的风险，Alpha 无法被合理预期做出反应。此类情况的例子包括极端自然灾害等新闻事件（超出了 Alpha 在其回测期间所见范围，除非 Alpha 是基于新闻或情绪的 Alpha，可以预期其利用该事件）、底层资产相关性结构的突然变化（如货币的挂钩或脱钩），或交易对手信用风险证据（假设 Alpha 此前将交易对手视为理所当然）——但最重要的案例是那些没有人预料到的情况。投资者有责任深入思考 Alpha 的失效模式，并在它们可能承担未预期风险时不进行交易。

## 结论

虽然并非所有风险都是可知的，但一些常见的外在和内在风险值得度量和控制。样本内业绩图表和汇总统计量只能揭示部分情况。对已知 Alpha 因子的敞口、持仓和损益的集中度以及回撤分布的分析，可以帮助研究人员了解他们所承担的风险来源，在适当的地方加以缓解，并安全地为其设定规模。
