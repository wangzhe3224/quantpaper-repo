# 第十五章：来自自动搜索的 Alpha

**作者：Yu Huang 和 Varat Intaraprasonk**

*Source: Finding Alphas: A Quantitative Approach to Building Trading Strategies, Second Edition. Edited by Igor Tulchinsky et al., WorldQuant Virtual Research Center. © 2020 Tulchinsky et al., WorldQuant Virtual Research Center. Published 2020 by John Wiley & Sons, Ltd.*

---

## 引言

"变化是生命中唯一不变的事物，"古希腊哲学家赫拉克利特在大约2500年前写道。他的这句话对当今的金融市场尤为适用。

我们生活在一个信息爆炸的时代。随着新数据源呈指数级增长，手动测试所有数据已变得不切实际。为解决这一问题，可以利用计算机算法在海量数据云中搜索 alpha 信号。这种计算机辅助方法被称为自动 alpha 搜索（automated alpha search），可以显著提高信号搜索的效率，在一天内生成数千个 alpha。但这是有代价的：并非所有发现的信号都是真正的 alpha。自动搜索发现的许多看似出色的 alpha 信号实际上只是对样本内历史数据的噪声拟合，并不具有预测能力。因此，任何自动 alpha 搜索的核心都是避免过拟合，以提高输出信号的质量。本章回顾了构建自动 alpha 搜索系统的过程。

## 效率与规模

自动搜索的主要目标是从指数级增长的输入与函数组合中，找出大量的 alpha 信号。这些组合还可以是递归的；组合的组合可以生成新颖的 alpha 信号。这种复杂性使效率成为自动搜索中最突出的问题之一。本章介绍了自动搜索所面临的独特问题，将搜索过程分解为与手动 alpha 搜索类似的可操作组件，并展示了效率的追求如何指导每个区域的不同处理方式。

自动搜索面临三个源于其大规模的问题：计算负载、无法手动检查每个组件，以及对每个 alpha 的信心较低。自动搜索通常通过试错法将不同的数据与不同的函数进行组合。因此，通常需要较高的计算能力。减少内存使用和提高速度的优化可以带来更多更好的 alpha。大量的组合也意味着不可能逐个手动检查每个生成的公式。即使想要手动调查样本，alpha 表达式也可能非常复杂，且没有明显的金融意义。此外，大量的试验意味着在数学和经济上毫无意义的组合可能通过幸存者偏差被错误地识别为 alpha。一个好的搜索过程应该从输出中剔除这类噪声——更好的做法是在一开始就防止其发生。最后，无法检查每一个 alpha 降低了研究者对每个 alpha 的信心，与手动制作的 alpha 相比更是如此。因此，自动搜索需要新的测试方法来维持 alpha 的质量。

为解决这三个问题，研究者可以考察任何 alpha 搜索（手动或自动）的三个主要组成部分：输入数据、搜索算法和信号测试（见图15.1）。输入数据是有意义的金融变量，如价格、收益和新闻。

任何信号搜索的目标都是利用这些数据来预测目标函数 Y，Y 可以是未来股票收益率或其变体。为了找到输入数据与目标函数之间的关系，使用拟合算法来确定预选试验函数族 f 的参数（最简单的例子是线性函数）。一旦找到 alpha，就对其稳健性进行测试。

## 输入数据不应来自过多类别

将过多的输入变量送入拟合算法会导致更好的样本内拟合，但通常会导致更差的预测能力，原因是过拟合。除此之外，一个经常被忽视的问题是数据类别的数量。此处的类别指的是数据的类型和来源。一些常见的探索类别包括但不限于价量数据、分析师评级、基本面数据、新闻和内部人交易。尝试容纳过多变量很可能导致过拟合结果，而从许多不同类别拟合变量往往更糟。每个类别的数据都有其自身的特征频率。例如，基本面数据通常表现出明显的季度周期，价量数据通常较为均匀，而内部人交易申报通常是随机间隔的。如果模型包含来自许多不同类别的数据，它通常会变得更复杂，更容易受到数据噪声的影响。

## 输入数据与无量纲比率

好的股票收益率预测因子应当在股票之间具有同质性和可比性。因此，价格和收益等原始金融数据通常不是好的预测因子，因为它们在不同股票之间不可比较。例如，收益的数值在横截面上不可比较，但收益除以收入是可比较的。原因是美元收益取决于公司规模。较大的公司通常有较高的美元收益，但较大的公司不一定有较高的股票收益率。同样，每股收益取决于股本大小，因此它们在股票之间也不可比较。然而，收益除以收入显示了利润率百分比，因此可以在股票之间进行比较。

同一类别中以相同单位测量的变量的比率通常具有可比性。另一种方法是将给定数据的当前值与其历史值进行比较。例如，当前价格除以过去一个季度的平均价格是一个无量纲变量，可以在股票之间进行比较。请注意，一些广泛使用的比率可能不适合用于自动搜索。例如，著名的市盈率 P/E（股价除以每股收益）不适合自动搜索，因为当收益值接近零时该比率可能发散。E/P 比率更为合适，因为价格永远不会接近零。同样，当前收益除以前期收益也可能发散。

这些使变量具有可比性的技术在自动搜索中至关重要，因为研究者无法检查每个 alpha。通过仅使用可比变量作为搜索过程的输入，可以减少系统中创建的无意义公式的数量——例如价格减去成交量。这通过减少搜索空间中的无关部分来减轻计算负载，并提高 alpha 的信心，因为这些 alpha 更有可能具有经济和数学意义。

## 不必要的搜索空间

在手动 alpha 搜索中，由于手动搜索空间较小，可以通过穷举搜索来拟合少量的参数和试验函数。这在自动 alpha 搜索中是不可行的；遍历整个空间所需的计算资源在实践中太大。因此，应尽可能缩小搜索空间。

一种可能的方法是筛选掉没有意义的函数和数据组合。例如，不能接受负输入值的函数（如 log）不应与股票收益率配对。人类知识可以用来识别和剔除一些不太有用的输入数据。例如，如果搜索的目的是找到短期信号，那么缓慢变化的数据（如行业分类）的变化可以从搜索空间中省略。检查时间覆盖率（数据变化或不可用的频率）和股票覆盖率（在给定时间有多少股票有可用数据）也有助于淘汰不太有用的数据。最后，迭代搜索首先在参数空间的粗网格上进行初始搜索，以找到可能存在 alpha 的区域，然后在该区域周围放置更细的网格。例如，在迭代搜索的第一轮中，动量公式可以分别拟合两个月和六个月的时间尺度。如果两个月的周期效果更好，下一轮可以使用一个月和三个月的周期。这种方法将过程分解为更小更快的步骤。它还产生中间结果，可用于即时改进搜索过程。迭代搜索也可以应用于试验函数，通过搜索能产生良好结果的函数的函数。

## 中间变量

进行手动 alpha 搜索时经常发现，涉及多个基本输入数据的简单函数的中间变量可以构成强 alpha。一个例子是前述的市盈率 P/E，它是价格和收益数据的组合。自动搜索也可能发现这样的有用中间变量，它们出现在许多 alpha 中。如果搜索系统能够记录这些变量并在其他搜索中重用它们，就有可能减少计算负载。同样，试验函数的组合也可以被记录和重用。这种对常见中间变量的重用是遗传算法（genetic algorithms, GAs）的基础之一，但对其进行全面讨论已超出本章范围。

## Alpha 之海，而非单一 Alpha

除了输入数据之外，搜索算法本身也可以进行优化。与手动 alpha 搜索通常在小参数空间中寻找单一最佳 alpha 不同，自动搜索在大搜索空间中寻找多个好的 alpha。因此，算法不应试图在搜索空间中找到全局最优，而是要在尽可能大的区域内找到尽可能多的局部最优。找到多样化 alpha 集合的能力不仅取决于搜索算法，还取决于搜索空间的定义方式。如前所述，研究者应事先过滤掉不合理的函数和数据组合，以便只遍历合理的搜索区域。此外，通过记录最有效的搜索区域，研究者可以将下一次搜索集中在这些区域以找到更多 alpha 并增加信心，或避开这些区域以寻找其他未发现的信号。在搜索空间中找到多样化 alpha 的能力是衡量搜索算法和搜索空间构建质量的指标之一。

## 简单的 Alpha

由于自动搜索可以产生大量 alpha，研究者可能倾向于不断增加函数空间的复杂性以获得更多 alpha。由于好的 alpha 通常很简单，这种基于深度的制造复杂 alpha 的方法容易产生大量在样本内看起来像 alpha 但在样本外表现很差的噪声函数。因此，研究者应限制搜索深度，更多地关注基于广度的方法，即扩展搜索空间——输入数据和试验函数。发现的 alpha 数量通常会增长较慢，但质量应该显著更高。

## 更长的回测期

增加回测期会增加可用的数据点数量并提高结果的统计显著性，但这仅在数据底层的动态相同的假设下才成立。这对金融市场来说并不总是成立的。市场参与者及其行为快速变化，进而改变金融市场动态。因此，在选择输入数据长度时需要权衡：如果周期太短，数据和结果的信心会较少；但如果周期太长，不断变化的底层动态可能使结果不太可靠。

在手动搜索中，人们通常对所捕获的市场动态以及它们预期持续多长时间有一定了解。自动系统缺乏这一优势，因此可能需要考虑定量方法来检测回测期何时过长，例如将回测分割并检查各期之间的一致性。以适度增加计算复杂性为代价，可以在 alpha 内部动态更新某些参数，而不是作为搜索的一部分进行拟合，从而使更长的回测期保持相关性。

更长回测期的另一个问题，特别是在大规模搜索中，是更高的计算负载。在迭代搜索中，增量回测期是一个有用的技巧，可以在不使用过多资源的情况下利用更长的回测期。例如，第一轮搜索使用从日期 M 到日期 N 的回测期。在下一轮，遍历较小搜索空间的更细网格时，使用 M - 0.5年到 N + 0.5年的回测期。在第三轮，使用 M - 1年到 N + 1年的回测期，以此类推。这样，第一轮（预期只有初步结果）的运行速度要快得多，而后期轮次（进行微调）使用更多数据点以获得更高的稳健性。将回测期扩展到每个连续轮次还在每轮增加了一个准样本外测试，使我们能够衡量产出率并在产出率高时增强对 alpha 的信心，或者在产出率低且幸存者偏差成为问题时中止搜索。

## Alpha 批次表现，而非单一 Alpha 表现

在人工研究中，每个 alpha 通常都有经济或金融推理的支持；alpha 的质量很大程度上取决于参数拟合的稳健性，这在各个 alpha 之间是独立的。因此，每个手动 alpha 的信心可以单独衡量。例如，可以从回测表现或参数敏感性测试中推断质量。相比之下，在自动搜索中，每个 alpha 背后没有预定的解释，因此对 alpha 的信心不仅取决于拟合算法，还取决于搜索空间。因此，询问单个 alpha 的质量不如询问整个搜索的质量更有意义。由相同搜索空间和搜索算法生成的 alpha 的综合表现称为批次表现（batch performance）。这类似于管弦乐队，其质量是基于整个乐团来衡量的，而不是个别演奏者的音乐。

选择偏差（selection bias）是一个常见的陷阱，源于对单个 alpha 的过度关注。完成自动搜索后，人们很容易测试每个输出 alpha 的样本外表现，并只选择那些表现良好的。然而，这种做法可能会在 alpha 批次中引入选择偏差，因为样本外表现已被用于 alpha 选择。因此，它不再能被视为样本外。为缓解这种偏差，应考虑批次中所有 alpha 的平均表现的统计显著性，并决定是接受还是拒绝整个批次。例如，假设产生了一批100个 alpha，样本内信息比率（IR）的截断值为0.15。经测试，这些 alpha 的平均样本外 IR 为0.01，IR 标准差为0.12。60个 alpha 的样本外 IR > 0，其余 < 0。在这种情况下，平均样本外 IR 过低，应拒绝全部100个 alpha，包括具有正样本外表现的60个。

研究批次统计量可以帮助发现系统中否则很难识别的错误。例如，一个系统被设置为使用季度更新的数据寻找低换手率 alpha，但输出 alpha 批次的换手率异常高。这可能指向参数拟合中的可能错误。批次统计量还可以产生关于输入数据和试验函数的有用信息；例如，在 alpha 批次中出现多次的数据或函数可能具有更高的预测能力。这些见解可用于进一步优化后续运行的搜索空间。

alpha 批次统计量的另一个应用是一种称为产出率测试（yield test）的技术。如果研究者使用一组具有经济或金融意义的搜索空间（输入数据和函数），她可以预期在该空间中发现的 alpha 数量高于从噪声数据输入或函数集合中发现的数量；也就是说，好的搜索空间应该比噪声搜索空间有更高的产出率。因此，研究者可以尝试将噪声输入送入自动搜索系统，并比较输出 alpha 批次的产出率和质量。基于噪声输入的批次应该比来自看似好的搜索空间的批次更差。如果无论使用好的还是噪声的输入，alpha 的数量和质量都没有太大差异，这可能表明整体过程存在缺陷，表明生成的 alpha 批次（即使是来自干净空间的批次）很可能也是噪声。

## 分散化 Alpha 批次

分散化投资组合具有较低的风险。这一原则也可以应用于来自不同自动搜索的 alpha 批次。每个 alpha 批次已经具有一定的分散化，因为它包含许多单一 alpha。然而，研究者可以通过改变输入数据集（例如基本面、价量数据）、试验函数（线性组合、时间序列回归）、表现测试（最大化收益、最小化风险），甚至搜索过程本身（不同的迭代过程）来增加批次级别的分散化。将来自多个批次的 alpha 组合起来可以进一步降低 alpha 之间的相关性和整体组合风险。

## 敏感性测试与显著性测试

好的 alpha 信号应该对噪声不敏感。对不同时期、不同持续时间的数据、随机数据子集、每个股票板块等进行交叉验证，可以是缓解过拟合风险以及噪声数据风险的好方法：我们对那些对这些输入变化不太敏感的信号更有信心。另一方面，每个输入数据字段都应对结果做出显著贡献。测试显著性的最简单方法是删除一个输入变量或用噪声替换它，然后检查结果是否发生显著变化。如果每个输入变量都做出显著贡献，我们更加信任该信号。

## 手动 Alpha 搜索

高质量的 alpha 搜索需要对输入数据、试验函数、搜索算法和表现测试进行精心处理。最初很难为每个部分确定适当的选择，尤其是在使用新的输入数据集或目标函数时。因此，在进行自动搜索之前，必须先对相同的输入进行手动搜索，因为复杂度较低，更容易理解每个 alpha 的各个方面。一旦清楚理解了输入，研究者就可以将过程泛化并使其适合自动搜索。

## 结论

自动 alpha 搜索相比传统手动 alpha 搜索具有许多优势——特别是效率和数量的显著提升。缺点是在几个方面需要谨慎。自动搜索可能加剧过拟合的程度，这可以通过仔细而有意义的变量选择、输入数据类别限制、测试期选择和敏感性测试来应对。这些都是避免过拟合和生成真正 alpha 的关键步骤。最后，通过考虑批次表现，改进和分散化可以应用于批次级别；这很难对通过手动搜索获得的 alpha 做到，因为相似的 alpha 数量较少，且难以将不同的 alpha 聚类在一起。随着人工智能领域的进步，我们预计自动 alpha 搜索将继续受到越来越多的关注和重视。
