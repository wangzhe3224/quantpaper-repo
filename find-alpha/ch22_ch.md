# 第二十二章：新闻与社交媒体对股票收益的影响

**作者：张万成**

*Source: Finding Alphas: A Quantitative Approach to Building Trading Strategies, Second Edition. Edited by Igor Tulchinsky et al., WorldQuant Virtual Research Center. © 2020 Tulchinsky et al., WorldQuant Virtual Research Center. Published 2020 by John Wiley & Sons, Ltd.*

---

## 引言

股票价格自然会对新闻做出反应。但近年来，社交媒体上的新闻和情绪作为股票价格的潜在预测因子，其重要性日益凸显。然而，利用新闻构建 Alpha 并非易事。作为通常包含文本和多媒体内容的非结构化数据，新闻无法被计算机直接理解。我们可以使用自然语言处理（NLP）和机器学习方法对原始新闻内容进行分类和打分，并可以衡量新闻的额外属性，如新颖性、相关性和类别，以更好地描述新闻的情绪。类似的技术也可应用于社交媒体数据以生成 Alpha，但应牢记社交媒体的数据量远大于传统新闻媒体，噪音也更多。本章概述了利用新闻和社交媒体寻找 Alpha 的方法。

## Alpha 中的新闻

机器很难准确地解析和解读新闻的含义。与统计套利中的其他领域一样，算法具有响应速度快、覆盖面广的优势，但代价是准确性不如人类分析师。如今，交易公司可以在1毫秒内分析新闻并立即做出交易决策。重大新闻通常会立即引发大幅价格波动，随后往往出现超调和反转。

自2007年以来，对新闻和社交媒体进行复杂语言分析的应用已从一个高度投机的研究领域发展为成熟的产品解决方案。专业数据供应商使用复杂的算法分析新闻并实时交付结果。新闻分析和新闻情绪被买方和卖方机构广泛用于 Alpha 生成、交易和风险管理。越来越多的大数据供应商提供套餐、服务或数据源，帮助企业将新闻用于投资流程。

## 学术研究

自2000年以来，新闻对股票收益的影响已成为一个热门研究课题。一些关键研究领域包括情绪的聚合与离散度、基于新闻的 Beta 计算、新闻领涨股、文本分析中的权重方案、日收益盈余公告对新闻的确认、"没有消息就是好消息"的理念、对新闻敏感的股票表现优于大盘的观点、成交量对新闻的确认、新闻报道中的偏差、新闻后的动量、超调和反转，以及新闻与分析师修正之间的关系。在社会科学研究网络（SSRN）上搜索"新闻"和"股票收益"可以找到相关论文。

第一篇关于利用社交媒体预测股票的研究论文是由 Johan Bollen、Huina Mao 和 Xiao-Jun Zeng 于2011年发表在 *The Journal of Computational Science* 上的《Twitter Mood Predicts the Stock Market》。该论文指出，通过分析 Twitter 文本，作者在预测道琼斯工业平均指数（DJIA）收盘值的每日涨跌变化中获得了87.6%的准确率。此后，关键研究领域包括各种形式社交媒体的预测能力、社交媒体应用于个股、社交媒体中噪音的讨论、通过观察转发和名人推文发现有价值的推文，以及社交媒体情绪与公司长期价值的关系。

## 情绪（Sentiment）

简单来说，情绪衡量的是新闻的质量。情绪最基本的定义是新闻的极性：好、坏或中性。高级情绪分析可以表达更复杂的情感细节，如"愤怒"、"惊讶"或"超出预期"。

新闻情绪的构建通常涉及自然语言处理和统计/机器学习算法（例如，朴素贝叶斯和支持向量机）。深度学习技术的近期爆发推动了新闻理解的快速进步。word2vec 等新技术相比经典 NLP 方法取得了更高的准确性。

情绪通常被标准化为分数（例如，范围为0-100），在资产间具有横截面可比性。按照惯例，较高的分数意味着新闻是正面的，较低的分数意味着新闻是负面的，接近50的分数意味着新闻是中性的。

单条新闻情绪可能受到市场整体情绪、季节性以及其他时间因素的影响（例如，在财报季之前或之后）。对于相对价值策略而言，比较相似股票之间的相对情绪是有用的。

情绪在风险管理中也很有用。例如，投资组合经理可能因意外新闻而减少某只股票的持仓规模，或者在估算投资组合协方差矩阵时考虑新闻情绪分数或新闻频率。

**示例**

一个简单的 Alpha 可以直接跟随情绪：

```
If (stock A sentiment > 70) long stock A;
if (stock B sentiment < 30) short stock B;
use the no-news stocks in the same industry for neutralization.
```

## 新颖性（Novelty）

新颖性衡量的是新闻是全新报道还是对旧报道的更新。供应商可能将一份长报告拆分为几个部分。有时，一篇报道是先前新闻的后续报道。在其他情况下，新闻可能在初次报道后被修改多次。新颖性较低的新闻通常对市场的影响较小，因为先前新闻中传达的信息可能已经被市场消化。如果我们将新闻视为时间序列中的事件，新颖性通常与事件之间的时间间隔成反比。

**示例**

我们可以通过使用新颖性来增强之前的简单 Alpha：

```
Score novelty from 0 to 1.
If (sentiment > 70) alpha = sentiment * novelty;
if (sentiment < 30) alpha = sentiment * novelty;
use the no-news stocks in the same industry for neutralization.
```

## 相关性（Relevance）

新闻可能对多只股票产生影响。相关性衡量的是新闻对特定股票的关注程度。某些新闻（如盈余或公司行为）是公司特有的，此类新闻的相关性通常较高。一篇新闻报道可能涉及某个产品供应链中的多家公司；在这种情况下，新闻对制造该产品的公司相关性最高，而对供应链上的其他公司相关性较低。

行业或宏观经济新闻通常对个股的相关性较低。一则关于银行业的通用新闻可能影响大量银行股；一则关于苹果新产品的新闻可能影响苹果和三星等竞争对手，对苹果的相关性较高，对三星的相关性较低。换言之，相关性将新闻情绪映射到个股。它可以作为增强新闻 Alpha 的另一个因子。

**示例**

我们可以通过使用相关性来增强之前的简单 Alpha，并忽略影响过多股票的新闻：

```
Score relevance from 0 to 1, get ns = number of stocks impacted by one news item.
If (sentiment > 70 and ns < 100) alpha = sentiment * novelty * relevance;
if (sentiment < 30 and ns < 100) alpha = sentiment * novelty * relevance;
use the no-news stocks in the same industry for neutralization.
```

## 新闻类别

除了将新闻简单分类为"好"或"坏"之外，进一步划分为更详细的类别可以增强新闻的分析和利用。一个类别可以很宽泛，如"盈余"，可能包括所有与盈余相关的报告，如盈余公告、盈余预测、盈余修正、盈余指引、盈余电话会议和盈余日历。也可以更具体，如"公司法律问题"。

使用新闻类别时需要考虑几个重要方面。首先，不同类别的新闻在市场中的反应时间可能不同。某些类别对公司估值有长期影响；其他类别可能引起短期价格波动。其次，市场在不同时期有不同的新闻风格。类别轮动策略可以利用这些新闻风格的变化。第三，某些新闻类别是特定于某些行业和板块的，可能仅影响那些行业或板块。最后，类别使不同类型的新闻更容易与其他类型的信息结合以创建 Alpha。例如，可以将盈余新闻与分析师盈余修正结合使用。像 Bloomberg 这样的新闻供应商为原始新闻提供标签和类别，通过高级机器学习方法进行的自动分类也越来越普遍。

**示例**

考虑盈余新闻的例子。我们可以去掉"市场报告"类别，并使用简单的"学习"方法进一步对新闻进行加权：

```
Ignore all news from the categories "market imbalance" and "market movements."
For each news category,
  Category_score = the average of relative stock returns after the news happened in the past two years
If (sentiment > 70 and ns < 100) alpha = sentiment * novelty * relevance * category_score;
if (sentiment < 30 and ns < 100) alpha = sentiment * novelty * relevance * category_score;
use the no-news stocks in the same industry for neutralization.
```

## 预期与意外新闻

一则看似正面的新闻，如果其信息已被市场预期并反映在价格中，则不会引发正面的价格变动。例如，一则新闻写道："盈余大幅增长——同比增长150%。"对此新闻的分析通常会得出正面情绪。然而，如果此前市场共识是公司将增长200%，那么新闻中的信息低于预期，将导致价格下跌。因此，将新闻数据与市场共识和市场预期结合使用会很有帮助。文本分析和日历分析在判断新闻是例行更新还是不同寻常的信息方面很有用。惊喜和意外新闻及事件通常会导致更大的价格波动。

## 标题与全文

标题通常包含最重要的信息且格式规范，因此更容易解析和分析。全文提供更详细的信息，但处理起来更困难。一篇学术论文展示了一个有趣的结果：段落中的大部分信息包含在首句和末句中。类似地，我们可以更关注文章的首尾段落，或首尾几个词。段落结构和句子结构也可以包含有价值的信息。

## 没有消息就是好消息？

俗话说："没有消息就是好消息。"这在某种程度上是正确的；新闻意味着变化、事件或异常情况的发生，而市场厌恶不确定性。新闻通常还与较高的波动性、较高的成交量、分析师修正以及更多新闻的预期相关联。这些方面意味着公司面临潜在风险。由于越来越多的公司在风险管理模型中使用新闻，机构投资者可能会减少频繁受到新闻报道影响的公司的持仓，甚至将其从投资组合中剔除。由于机构投资资金流通常对股票收益有正面影响，这可能降低收益。

**示例**

当某公司的新闻数量异常多时，做空该公司。

## 新闻动量（News Momentum）

如果新闻对股票的影响没有被市场立即且充分地定价，股票价格可能会随着新闻被更广泛地传播和理解而呈现漂移或动量效应。这种效应对于小盘股更强，因为它们受到的关注较少；对于意外新闻也是如此。对于大盘股和预期新闻，价格通常在初始超调后呈现反转。

**示例**

在新闻发布后的前三天，按照新闻发布前两天的两天股票收益方向持仓；在随后的五天内，反向交易以捕捉反转。

## 社交媒体

2013年4月，美联社的一条 Twitter 帖子声称白宫发生爆炸，奥巴马总统受伤。这条推文是虚假的，但在市场上引发了巨大的即时反应。从下午1:08到1:10，道琼斯工业平均指数下跌了超过140点。尽管指数同样迅速地反弹，但一条虚假的 Twitter 事件造成了1360亿美元的市场损失。这个案例清楚地展示了社交媒体在算法交易中的巨大潜在价值。许多数据供应商正在抓住这一机遇。像 Dataminr 和 PsychSignal 这样的公司每天提供数百万条社交媒体数据流。它们还向第三方供应商提供数据，用于创建许多对冲基金使用的情绪产品。

Twitter 是生成 Alpha 最受欢迎的社交媒体平台，因为它可以轻松地映射到股票（通过检查 @ 股票代码）和人物（如上市公司的CEO）。基于 Yahoo Finance 论坛和 StockTwits 等在线论坛、专业投资者和交易员的博客、Facebook、Glassdoor 甚至 Wikipedia 的研究也在不断增加。

社交媒体目前是量化研究的热门领域。本质上，社交媒体可以被视为新闻，但数据量更大、噪音更多。许多适用于新闻的方法也适用于社交媒体，但在对社交媒体内容应用情绪分析时存在几个挑战。首先，社交媒体的记录数量更大且更新更快。其次，社交媒体内容在格式上通常比较随意——例如，一条 Twitter 帖子可能包含大量缩写和格式不规范的语言。这增加了语言处理的难度。第三，我们如何找到原创且重要的记录？大量社交媒体内容是对新闻的回应，其影响力不如更具原创性的社交媒体内容。因此，社交媒体中存在许多虚假信号，这也是利用社交媒体进行预测较为困难的原因。

**示例**

利用推文频率和转发次数做空被提及频率不断增加的公司（关于公司的推文大部分是负面的）。

```
For each company, calculate the number of tweets that mentioned
the ticker symbol or company name on a particular day.
Get the number of retweets for each tweet and set it as t.
Set frequency = sum of log(t + 1).
Alpha = -time_series_rank(frequency, 1 month) ^ 0.5
```

## 结论

新闻、社交媒体内容和处理大数据的公司数量正在快速增长。越来越多的市场参与者使用自动化方法来分析和交易这些信息。因此，每条信息对股票收益的平均影响可能会随时间递减。要继续在新闻中寻找 Alpha，人们需要解析更多新闻，找到最有影响力的新闻，过滤噪音，并采用更先进的机器学习方法来学习和分类新闻。
