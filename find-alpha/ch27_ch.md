日内交易（intraday trading），又称日间交易（day trading），是指在同一个交易日内买入和卖出金融工具的投机行为。常见的日内交易金融工具包括股票、期权、货币以及各类期货合约，如股指期货、利率期货、货币期货和商品期货等。严格来说，所有日内交易的头寸都在市场收盘前平仓。然而，许多交易者将日内交易作为整体策略的一个组成部分。以盈利为目的进行日内交易的交易者被视为投机者，而非套期保值者或流动性交易者。这种快速交易的方法与买入并持有（buy-and-hold）和价值投资策略所基于的长期方法形成鲜明对比。

交易者在同一天买入和卖出金融工具似乎并不稀奇，但日内交易实际上是一个相对较新的概念。虽然这种做法可以追溯到1867年第一台股票自动报价机的发明，但当时存在显著的准入壁垒，因此这种交易方式并未在普通民众中普及。日内交易随着1969年Instinet等电子通信网络（ECN）的创建、1971年全国证券交易商协会自动报价系统（Nasdaq）的建立，以及1975年固定佣金费率的废除而开始流行。

日内 Alpha 试图把握交易的进出时机，以从日内价格波动中获利。从日频 Alpha 研究转向日内 Alpha 研究需要在风格和方法上进行某些调整。本章将介绍构建日内 Alpha 的不同风格，首先从日内 Alpha 构建的一些基本差异入手。然后我们探讨日内交易相对于日频交易的优缺点。之后，我们将讨论构建日内 Alpha 的不同方法，并给出若干示例。

## 日频交易与日内交易

构建日频 Alpha 可利用的信息来源非常广泛，从公司资产负债表到社交媒体再到天气数据。然而，构建日频 Alpha 所使用的大部分信息源在日内研究中并无用处，因为它们的时间跨度太长。但是，其他信息源——包括买卖报价快照、详细的订单簿数据以及其他微观结构数据——在更短的时间跨度上具有预测能力，因此对日内研究更为有用。

一般来说，随着分析师向更高频率的研究方向推进，可用的信息和数据来源的多样性会降低。在进行日频研究时，分析师不太关注单个 Alpha 相对于成本的表现，因为可以对多个不同的 Alpha 进行交叉组合。但在日内研究中，由于缺乏足够多样化的信息来源以及净对不同 Alpha 的能力较低，成本在 Alpha 层面成为一个需要关注的问题。下文在解释构建日内 Alpha 的过程时会涉及这一点。

日内研究相比日频研究具有一些显著优势。由于可以在更精细的时间尺度上进行交易，日内 Alpha 的表现和收益通常更高。即使在较短的回测期内，日内 Alpha 的统计显著性也远高于日频 Alpha。因此，Alpha 的样本外表现与回测期内的表现非常接近。

在构建日频 Alpha 时，分析师会尽量使 Alpha 对所有可能的隔夜风险保持中性，如美元 delta 敞口、行业敞口等类似风险因子。然而，在处理日内 Alpha 时，大多数风险因子在某一阈值之下是可以接受的，因为如果这些头寸与 Alpha 走势相反，可以立即平仓。这为利用这些风险因子来提高收益提供了机会。

流动性（liquidity）被定义为资产在市场上的可获得性。在任何特定时间，只有一定数量的交易量。换句话说，任何时刻的流动性都是有限的。如果某人在某一时刻交易了占当时交易量很大比例的数量，她就面临自身推动价格变动的风险，从而使交易执行更加困难。大多数可交易工具在日内没有足够的流动性来支持全天频繁交易。这使日内交易局限于每个地区流动性最高的工具。例如，在美国，除了流动性最高的200–500只工具外，其他工具很难进行日内交易。这反过来又导致日内策略的可能资金配置规模较小。

## 日内 Alpha 的不同类型

日内 Alpha 有不同的风格。日内 Alpha 的经典定义是 Alpha 不持有任何隔夜头寸。这类 Alpha 被称为 overnight-0 Alpha。类似地，overnight-1 Alpha 是同时持有隔夜头寸的 Alpha。一般来说，这类 Alpha 要么持有未平仓的头寸过夜，要么以日内叠加（intraday overlay）的形式作用于隔夜头寸之上。在 overnight-0 和 overnight-1 Alpha 中，Alpha 可以在不同工具之间连续分配头寸，也可以采用更离散的基于入场或出场的信号。在基于入场或出场的信号中，交易根据某个指标或某个派生统计量的异常变化（称为"事件"）进入，头寸持有一段时间直到满足某些出场触发条件。这些出场触发条件可以是派生统计量的变化，也可以是止损或止盈条件。

在设计日内 Alpha 时，分析师需要牢记若干约束条件。首先，流动性在一天中并不均匀。它通常如图27.1所示，大部分交易发生在一天的开始和结束时段。部分股票在交易日开盘时具有很大的滑点——例如微软公司（MSFT），如图27.2所示——在这种情况下，在滑点较小时进出这些证券的头寸通常是明智之举。此外，请记住并非所有金融工具的行为都相似，尤其是在为交易所交易基金（ETF）和期货构建日内 Alpha 时。对于许多类别的策略思路，工具需要单独处理，或按相似工具的小组进行分组。

## 构建日内 Alpha

以下是一个简单均值回归 Alpha 的示例。分析师希望捕捉金融工具的回归特性。Alpha 定义为：

<!-- Formula: alpha = second_last_interval_close − last_interval_close -->

这是一个针对流动性最高的500只工具的 overnight-0 连续 Alpha。然后通过减去截面均值来中和头寸，使每个时间间隔保持美元中性（多头和空头头寸相等）。

通过更深入的理解可以改进这一思路。这是一个均值回归策略，分析师试图捕捉工具向均值回归的趋势。波动性更大的工具应具有更强的回归倾向。我们可以通过多种方式来捕捉这一点。下面给出其中一种方法。只需取过去30–40个区间的收益率或价格的标准差，并将 Alpha 值乘以该标准差：

<!-- Formula: alpha = (second_last_interval_close − last_interval_close) × std_close -->

这提高了利润率（margins），但降低了夏普比率（Sharpe ratio）。理解其中的原因很重要。引入乘数因子同时增加了 Alpha 的收益和波动率，但波动率是夏普比率的分母，这两个相反力量的净效应是降低了整体夏普比率。

分析师可以尝试通过以下方式降低 Alpha 整体的波动率：

<!-- Formula: alpha = (second_last_interval_close − last_interval_close) / std_close -->

这降低了 Alpha 的波动率，从而提高了夏普比率，但同时显著削减了收益和利润率。

Alpha 的设计选择取决于交易者的需求。前一种具有更高利润率的版本在考虑交易成本后表现更好。可以尝试使用 std(close) 的截面排名（cross-section rank）代替绝对值来构建该策略的变体。

## 结论

日内交易与日频交易存在显著差异——在日频交易中，分析师可以从各种来源收集信息。与此同时，某些具有短期预测能力的信息——如买卖价差和其他订单簿层面的信息——在日频交易中几乎无用，但在日内交易中却具有显著的潜在价值。

日内交易受到大多数金融工具流动性有限的制约，这通常将日内交易者局限于流动性最高的工具。但有限的交易规模被日内交易产生的更高潜在收益所补偿。日内 Alpha 可以是不同类型的——从完全不持有隔夜头寸的纯日内 Alpha，到持有隔夜头寸但通过日内叠加提高收益的混合日频-日内 Alpha。
